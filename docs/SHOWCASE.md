# 示例作品 / Showcase

These are existing character-media and editing examples made with the Battle Scaling workflow. They show source selection, collage, layout, timing, reveals and export. The videos' attribute assignments and difficulty labels are demonstration settings, not a current canonical rating report. Creating a production matchup still uses the independent research workflow.

以下成图与样片展示实际媒体能力：选材、排版、卡点、揭晓与导出。视频中的给分和难度为演示配置；正式论战仍须完成独立评级。样片不是需要安装的运行依赖，也不会把其中的镜头变成原作能力证据。

The looping GIFs on the home page are short, silent selections; the MP4s preserve the full sample edit and audio. Display copies are resized for the web. The editable video system offers V01–V09 independently; these two examples both use V04.
