# Distribution content boundary

The current package includes independently implemented research/rating/writing tools and the explicitly licensed or attributed material described in [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md).

Source scans and screenshots, complete works/OCR, complete example stories, reference audio/footage, user projects, credentials, machine configuration, model weights and runtime databases are not bundled. Existing runtime libraries are not synchronization destinations.

Handbook transformations retain rules, units, formulas, standard identifiers, mathematical bridges, source fingerprints and page locators. Nonfunctional historical case dossiers and page-inventory commentary are omitted, following the established content boundary. Redundant long quotation metadata is removed without deleting functional conditions or calculations.

Writing uses independently worded [methods](../skills/battle-scaling/references/writing-experience.md). SCP-derived benchmark excerpts/paraphrases retain author/source links and CC BY-SA3.0; VSB adaptations retain their own CC BY-SA3.0 attribution. Video dependencies and the font retain the Remotion License and OFL1.1 respectively.

The current-file review does not rewrite or audit Git history and is not a warranty of rights clearance. See [synchronization](PUBLICATION-SYNC.md), [distribution details](public-distribution.md) and [current package provenance](CURRENT-RELEASE-AUDIT.md).
