# Current distribution content and provenance

Target version: **1.21.0**. This document covers the current distribution files, not Git history.

## Contents

The package keeps integrated ratings and nine attributes, both rule standards, canonical evidence workflows, finite/high-tier computations, source/state propagation, battle writing, the novel dossier tool, semantic-boundary exercises and the editable comparison-video tool. The host researches, reads and makes semantic judgments; programmatic structure/integrity checks do not certify those judgments.

The full distribution also includes poster and collage assets, media discovery/acquisition and QR download adapters, scarce-character/generation-backend instructions, reference-video template replication, lightweight dependency profiles and an isolated installer. The video bridge discovers the repository layout or uses an installed runtime pointer; collage can use the included OFL font without a machine-specific system font. See [setup and capability coverage](INSTALL.md).

Functional handbook rules, named tiers, units, formulas, mathematical bridges, page locators and original-source fingerprints remain. The established transformation omits nonfunctional historical cases and trims page-inventory commentary and redundant long quotation metadata. It does not replace full rules with a reduced public rule set.

The independently written [writing methods](../skills/battle-scaling/references/writing-experience.md) remain the writing reference. No complete example story, renamed replacement story, dialogue excerpt or story retelling is supplied as writing instruction. Retired example-index links point to the methods document.

## Material and license boundaries

Original scans, complete OCR, original-work screenshots, complete novels, runtime/access libraries, machine configuration, credentials, external model weights, reference songs, footage and user character media are excluded. The video project retains production code and timing/effect parameters, original reusable graphics, and the unchanged OFL font. Its empty preview prompts for user imports.

Original software/documents use MIT with explicit third-party exceptions. Remotion uses the Remotion License; Smiley Sans uses SIL OFL1.1. VSB adaptations and SCP-derived benchmark excerpts/paraphrases use CC BY-SA3.0 with attribution and source links. Full details are in [third-party notices](../THIRD_PARTY_NOTICES.md) and [NOTICE](../NOTICE.md). Acknowledgement and successful operation do not grant rights to underlying media.

## Validation

[Repeatable synchronization](PUBLICATION-SYNC.md) excludes source/runtime material, preserves the writing methods bytes and builds public static manifests. The Skill manifest covers Skill files; distribution-manifest.json covers the other static tools, notices and docs as well. Verify with `python -X utf8 tools/verify_package.py`.

The current distribution validation results are recorded in release-validation.json. It includes executable tests, rather than treating JSON parsing or hashes as proof of correctness. Run checks again when source or distribution bytes change. These checks are not semantic, literary or legal certification.

The optional generated DEATH BATTLE! cover variant retains its adjacent generation prompt and carries a specific third-party brand exception in the notices. Its wording is not represented as project-owned or MIT-licensed.
