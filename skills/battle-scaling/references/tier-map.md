# 从物理表现到论外的量级导航

此页下文为汪吧导航。`standard=vsb` 时改查 [VSB标准切换](vsb-mode.md)、[属性与数值](vsb-attributes.md)及[高层条件](vsb-high-tier.md)，不沿用此页社区档名、能量切点或无限盒子映射。

这是检索、建模与具名规则映射的导航，不能取代具名校勘规则的完整条件；已有适用校勘与工具时直接复用，仅尚未校勘的量级册内容回图，详见 [复用协议](handbook.md)。当前默认改为 [2026.7.30用户提供量级册](handbook.md) 的校勘规则；下文2024能量表及2025的N形式均保留为显式历史口径。本册第250页使用序数叠法，不默认套用旧N映射。天体与宇宙结构按目标和终态研究；高层按具名版本。用户指定标准时优先核验该标准，不把不同表的同名档位拼成一个无条件总序。

## 数学及社区形式映射

`rulesets/high-zerozhi2025-new.json`保留单体N、多元N²、无限多元N³、全能N⁴、有限高阶、N^N及更高形式。这个N是**所选社区的形式对象**；把N认作某个超实数还需给具体模型，不能说所有无限超实数必然服从同一个分档。[零智2025整理](https://www.bilibili.com/opus/1022449834228973569)并列旧ℵ₁论外门槛和另一套新门槛；这些是规则约定，不是数学定理。

具名AOS／404中的旧神盒四阶及更高档见`high-wiki-aos404.json`与`high-tier-cases.md`。论外没有一份已确认的2026统一官方总表。若任务需要新档位，实际检索其定义、发起者、日期与撤销／修订状态，保存新增规则，不用“网上普遍认为”代替证据。

## 有限高档缺数值时继续完成

1. 已有官方“摧毁太阳／星系”的明确战果，可以先给目标对应的定性档位；若需焦耳，查该版本目标物性及破坏终态后计算。
2. 均匀太阳近似可以调用`gravitational_binding`，但真实恒星有密度分层；用质量半径并不自动得到严格下界。星系非均匀球，需质量分布与势能模型；宇宙尺度还需处理膨胀和广义相对论，不机械套牛顿均匀球。
3. 分清“摧毁所有天体”“抹除空间／时间线”“创造／支配整个结构”。只有能量机制有依据时才使用J；空间、因果或叙事能力可给作用域量级，攻击和耐久另证。
4. 表内最高有限参考点不是角色上限。工具返回超表时，按以上流程继续研究相应高档，给条件范围或定性结论，同时保留参数和出处。
