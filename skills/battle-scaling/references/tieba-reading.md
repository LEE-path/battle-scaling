# 贴吧搜证：匿名接口、分页、楼中楼与图片出处

关键词：`tieba`、汪峰在、抖音论战、角色名、表现、评定组、总集帖、楼层、楼中楼、原图、断点。帖子中的评级／解释保持社区资料身份，其中已核出处的原作图文可单独建原作证据；楼主、吧务或评定组的身份与说法仍需核查，不能自动覆盖用户锁定的量级表。

## 角色定档的固定搜证入口

允许网络搜证时，先执行以下汪吧三路查找，相关资料不足时再启用第4路抖音论战吧补查；与原作、官方和其他站点交叉核验。该优先顺序不延后原作取证，也不要求先穷尽汪吧；用户限制资料范围时遵守该范围。

1. **总集帖找评级详情**：查 [【评定组】评定组角色作品量级评定贴总集贴](https://tieba.baidu.com/p/8939354620)。检索角色名、别名及作品名，进入其二级链接读取具体评级、原图、叠法、反驳及修订。总帖部分楼层仅有链接，不能只对总帖正文搜名字就宣布未收录；必要时先取链接帖标题／首楼，再筛候选。区分总帖楼主收录、其他用户补链、详情楼主结论与楼中楼个人意见。总集帖是导航入口，不是统一量级表。
2. **吧内搜角色**：在 `forum:"汪峰在"` 查询角色名及别名，再按作品／动画或漫画／时期／形态细化；同时查“量级、评定、叠法、重评、反驳、破防”等正反线索。读命中帖正文与关键回复，保留日期、适用版本及旧评／新评差异；没有身份核验，不因标题有【评定组】就按中可信处理。
3. **吧内搜具体表现**：角色名＋招式／能力名＋动作或场景词；必要时以作品名、对手、地点、章号及原语言原词补搜。搜索既可找量级讨论，也可直接找原图或官方片段。文字命中后追查对应章节、页格、集数／时间戳和前后文；不将多人重复转述当多份独立证据。仍无原作依据则登记未证实，排除该表现的定级用途。
4. **汪吧不足时补查抖音论战吧**：入口为 [贴吧“抖音论战吧”](https://tieba.baidu.com/f?kw=%E6%8A%96%E9%9F%B3%E8%AE%BA%E6%88%98&fr=frs)，现有贴吧工具使用 `forum:"抖音论战"`，不是抓取抖音App。相关角色／版本条目、关键原图、叠法前提、反例或后续修订不足，或关键链接失效时，按第2、3路的角色名／表现查询补查，并记录触发缺口。优先检查匹配角色的评定组资料，分区或标题标签只作导航；个人评定、普通讨论及楼中楼仍逐条分级。两吧转载同一论证保留原始帖与传播关系，不作为额外独立证据。

每路记录实际查询式、范围／分页、命中帖ID、楼号／PID、图片URL、原作定位及已读部分；未访问的详情只作待办。总集帖与吧内检索不保证覆盖全部资料，不能只看头两页就称全吧没有；默认排序曾返回大量早帖，应核日期，按需扩大分页或用网页搜索交叉查漏。

两吧可信度与采纳统一按 [证据协议](evidence.md#汪吧资料的可信度与采纳)：**已核评定组评级／叠法中，普通搜帖讨论低；原作出处、版本、上下文已核且实际读过的原图高；无证纯文字转述仅线索，未核前不参与综合定级或交手依据**。高可信只覆盖图中支持的事件／声明，不自动证明焦耳值、全力上限、体防继承或社区给出的量级。直接取得并核实的小说原文照常可用，来源换吧不更换定档规则。

例如搜索请求：

```json
{"op":"search","forum":"汪峰在","query":"角色名 招式名","max_pages":2,"rn":30,"output_dir":"./research/角色表现搜帖"}
```

另以角色名／别名查询，并用 `thread` 追读命中帖；该示例不表示已搜索、已核原图或只需两页。

启用补充入口时，将搜索请求的 `forum` 改为 `"抖音论战"`，并使用不同输出目录，避免混用汪吧缓存。网页打不开时按下文复测匿名接口；取得摘要不代表已读评级正文或核过原作图。

## 已实测路径与可选依赖

2026-10-20在Windows实测：普通HTTP页面返回百度安全验证；`aiotieba==4.8.1` 的匿名公开客户端接口可读吧内搜索、帖子列表、正文分页、楼中楼与图片地址。先查站点档案，再对本次目标少量复测；成功不代表整个站点永远可用。

主工具为 `python scripts/battle.py tieba --input request.json --output summary.json`。编排器使用标准库；独立worker使用[aiotieba](https://github.com/lumina37/aiotieba)，只调用 `get_threads/search_in_forum/get_posts/get_comments`。不包含发布、回复、点赞、删帖或管理接口，不接收凭证、不提取浏览器Cookie。SDK实际接口见[上游文档](https://aiotieba.cc/ref/client/)。

依赖已存在时直接使用。需要安装时，在独立Python 3.11+环境安装 `aiotieba==4.8.1`，将环境中的Python路径写入 `BATTLE_TIEBA_PYTHON`，或本机 `runtime/local-tools.json` 的 `tieba_python`。公开分发不包含本机路径或venv。`{"op":"doctor"}` 只检查依赖，不宣称网络可用。

## 读帖请求

```json
{
  "op": "thread",
  "url": "https://tieba.baidu.com/p/8436431500",
  "max_pages": 10,
  "include_subreplies": true,
  "max_comment_pages": 20,
  "max_requests": 100,
  "delay": 1.0,
  "resume": true,
  "output_dir": "LOCAL_BATTLE_WORKSPACE/03_作品与原始证据/贴吧任务"
}
```

`tid` 可代替URL。`pn` 默认1，帖子 `rn` 默认30、最多30。不同吧/搜索词/帖子或页大小应使用不同输出目录；程序拒绝覆盖不同任务。输出目录应在Skill包外。`max_pages` 默认3，所有操作均受预算限制；`max_requests` 统计worker页操作，SDK内部可能另外解析吧ID，不能冒称已精确统计底层HTTP请求。请求间隔最低0.5秒。遇限流/验证码或失败停止新增网络请求，保留已取页面；不自动解验证码、换身份或无限重试。只有确认普通瞬时错误后，才作有界重试。

帖子正文 `get_posts` 不混入高赞评论预览。按每楼 `reply_num>0` 单独分页调用 `comments`；主楼完整、楼中楼完整分别评估。服务端声明数量可能包括已删除/不可见内容，保留 `reported_replies` 与 `retrieved_replies` 的差异，不伪造缺失内容。

## 搜索、吧列表与独立评论

```json
{"op":"search","forum":"汪峰在","query":"神盒","max_pages":2,"rn":10,"output_dir":"D:/论战资料/神盒搜帖"}
```

```json
{"op":"forum","forum":"汪峰在","max_pages":2,"rn":10,"output_dir":"D:/论战资料/吧列表"}
```

```json
{"op":"comments","tid":"8436431500","pid":"147727407658","max_pages":5,"output_dir":"D:/论战资料/该楼评论"}
```

吧名通常不附加末尾“吧”。搜索结果是平台检索返回的摘要/匹配楼，不是全文；记录帖ID与匹配楼ID，随后用 `thread` 读取。搜索排序与总数不保证准确或穷尽；只抓两页应报告分页范围和 `partial`，不能称全吧搜完。`only_thread:true` 只搜索主题，`only_thread_author:true` 只看楼主，默认均为false；缩小范围后不能宣称全体回复已取。

## 输出与核读

- `result.json`：实际条目、正文、楼号、作者公开显示名、时间、原文链接、逐页/逐楼覆盖和缺口。
- `report.md`：可直接阅读的主楼或搜索条目；楼中楼完整记录在JSON，按需阅读。
- `image-links.json`：源响应真实提供的原图/大图/缩略图地址及所有引用楼层，不自行拼高清URL；图片地址取得不代表图片仍可下载、已读图或完成OCR。读漫画证据继续走媒体阅读和视觉协议。
- `sources.json`、`pages/`：逐页不可覆写的SDK解码快照、请求、时间、哈希、源ID；这是实际SDK响应的规范化快照，**不是原始HTTP字节**。`*.latest.json` 只是断点缓存指针。

主楼结束要核对请求页、返回页、总页和 `has_more`；矛盾、重复页、未确认结束、预算耗尽均不能判完整。完整只指所选范围内当前接口可见数据，不包括已删/屏蔽/不可访问楼层，也不保证原著取证完整。

`resume:true` 校验哈希后复用成功快照，只抓缺页；复用保留旧时间，`live_revalidated:false`。需要本轮全部重新访问用 `resume:false`，旧回执路径继续有效。勿把全缓存重跑说成重新核验了当前站点。

抓取器向独立站点库记 `fetched_unreviewed` 或具体错误；Agent实际核读正文及目标身份后再追加 `readable/partial`。只为贴吧的纯数字 `pn/tid/fid/pid` 保留查询定位，不保存凭证、签名或其他敏感查询字段。

## 浏览器补录

若匿名接口不可用，可按宿主工具检查浏览器公开页面或用户已有会话。本机OpenCLI 2.0.0曾实测 `tieba search/read`，但其搜索仅第一页，`read`只抽当前DOM可见回复且缺图片和完整楼中楼；不可拿该输出冒充全帖。公开[adapter说明](https://github.com/jackwener/OpenCLI/blob/main/docs/adapters/browser/tieba.md)需与当前安装代码共同核验。没有相应浏览器工具的Agent不能宣称使用了该路径。
