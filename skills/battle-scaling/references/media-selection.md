# 媒体素材的用途、优先级与兜底

先执行[媒体审片与返工铁律](media-review.md)。比较底板、揭晓、长展示与海报按各自真实用途审，不能只看源图或一个代表帧。

角色素材能下载，仅说明取得方法可用。正式选材还要实际看人物版本、主体分量、神态／动作、视觉质感和剪辑位置；不能下载第一段就停止寻找更合适的画面。本模块独立于量级、属性证据与胜负，不运行数学验收或新审批。

## 先问这段画面负责什么

- **intro 开场**：登场、靠近、变身、亮武器、能力或有气势的站姿，快速交代身份和状态。可以按角色性格采用平静、傲慢、轻松、狠厉或恐怖，不强迫所有人咆哮。
- **plate 比较底板**：主体大、构图稳、给文字留位置的头肩／上身／核心近景；必须在实际半屏保住面部或主要识别锚与动效余量，不能只剩下巴/胸口。视频取足够长的单个连续镜头，窗口内不夹切镜、不循环凑长；可在不同维度之间复用。短而稳定、气质鲜明的镜头常比复杂混战好读。
- **highlight 单项揭晓**：先通过下述即时辨识硬门槛，再比较档位与气势。给分镜头可以作为身份反馈重复用，不要求画面恰好实演该属性，也不从这段展示反推属性结论。
- **finish 结尾**：笑脸、凝视、从容停驻、强者姿态或可持续观看的动作高光，让结论有情绪变化；素材里的另一个交战对象不冒充本场跨作品对手。

同一来源不同片段可以有不同用途与优先级。画面朝向、人物尺寸、裁切焦点、字幕位置和转场窗口都要放进实际版式看；近景、漫画式动效、静态图和原生动态分别发挥长处。来源官方、标题4K或动作很多不自动成为高档。

胜者长展示需完整保留宽画幅动作时，按[同源模糊填充](video-editing.md#默认结构与素材分工)在清晰前景后铺同步、放大且柔化压暗的原片，替代纯黑留白。背景是氛围层，不拿模糊后的主体充当揭晓辨识证据；正常的品牌黑底片尾不随之改动。

## 维度揭晓的即时辨识硬门槛

揭晓视频另须为覆盖完整槽位的单个连续镜头；镜头内不能有隐藏切换、其他机位闪现或回卷。人物在中间一帧清楚也不能豁免首尾异镜，按[审片流程](media-review.md)完整查所用区间与最终接点。

**本门槛只用于维度胜负揭晓短镜头。先判断清楚可辨，再评S/A/B/C；即使原评S档，未通过也不得采用。**在最终画幅、裁切、实际展示时长和转场动效下，观众应能迅速看清主体并认出是哪位角色，从画面明确接收到该项胜者。不能仅凭光效颜色、前后文或“熟悉原片就知道”补足身份。

露脸不是唯一条件：清楚的全身、独特轮廓、面具、战衣、核心或标志装备也可构成可靠视觉锚点；这些特征须在短暂展示中足够明显。高亮能量、粒子、烟雾、暗部、运动模糊或构图遮挡若吞没主体和辨识特征，即不通过。转场后须留下足够清楚的识别窗口，不能只在某一张暂停帧中勉强认出人物。

先按真实速度看这一揭晓及前后衔接，疑点再抽帧定位；分别看每位角色的两段候选，不能因其中一段清楚就放过另一段。未通过者直接撤出highlight候选池，沿用现有`qualityTier: exclude`标记该用途候选；不只降为B/C继续轮换，也不为凑两段而采用。若同一源片仍适合其他用途，另留相应用途的有效区间，不能把已否决的揭晓候选改成`any`绕回池中。优先补选清楚可辨的镜头；只有一段合格时，沿用单段重复的兜底，不以不清楚的第二段凑数。

导出后按实际揭晓速度视觉复核；裁切、变速或动效影响辨识时重看受影响镜头，未通过就调整或替换。该门槛是选材和成片的视觉判断，工程只执行已标记的排除，不冒称自动识别人脸或判断清晰度，不新增数值评分、程序验收或评级检查。

视频选材按[段落基准与模板优先级](video-editing.md#默认结构与素材分工)分别留出开头、固定比较底板、每人两段揭晓、总胜者片尾；布局与实际段长遵循所选音乐模板，全屏轮播不能套成其他模板的分屏，模板没有长尾也不硬加。长展示按下节先比精彩程度；精彩长段优先于精彩短段，精彩短段又优先于为凑时长拉长的长段；确需连播时各段时长尽量接近，内部不重复，也不与其他展示位置复用；中段底板跨维度复用和两段揭晓轮换按各自用途保留。源片可相同，实际镜头应不同且不重叠。合适片段允许慢放至最低0.5倍速匹配长度，不能靠改裁切／变速把同镜头当作新素材，也不拉慢音乐来凑画面。

## 干净片源与精彩优先

**优先最终可用画面干净、清楚的素材。**先找无额外水印的高清源片；B站等源片的水印、黑边与字幕若处于边缘，可以先裁切再评档，不因源文件带字就直接排除或降级。先定位有效画面区，把边缘水印、字幕与黑边一起裁去，再实际看目标版式下人物、脸部、装备、动作和作用画面是否保留，剩余真实分辨率是否够用；裁后仍干净高清、主体完整的可列首选。不要通过裁掉人物、关键动作或大幅牺牲清晰度强行去字；还在脸／核心上的明显水印、二创署名、硬字幕或覆盖，以及裁后观感受损者，才降低优先级。放大像素不增加细节，抹除／模糊水印也不是默认补救方法。原生服装图案不算上传者水印。

**先看精彩程度，再看连续性与段长。**先以原速观察人物动作、能力效果、力量作用、情绪变化和人物张力，再结合音乐判断是否值得持续观看。干净、4K、连续、足长或做成一个MP4，都不等于精彩；低信息密度的等待、反复蓄势和收招后的停顿应缩短或换掉，不能靠慢放硬凑。

有持续展示需求的开场、收尾默认按以下顺序择优：

1. 足够精彩的长段连续表现。
2. 几个足够精彩的短段衔接。
3. 为匹配时长而拉长的长段。
4. 普通但合格的短段。
5. 多个动图／动效片段切换。
6. 多个图片加动效切换。

原作正常切镜可以保留；连续段与拼接段都须服务于目标角色，不能夹入无关人物的独立镜头。这个顺序比较可用展示方案，不要求每层都试一遍；明显糊、身份不符或主体不可辨的实机不能凭“视频”形式越过清楚可用的图片。底板与短揭晓仍按各自功能择镜，海报／一图流不继承动态素材顺序。允许适当慢放精彩动作，但不得因此降低整体观感；精彩短段优先于拖慢后勉强够长的连续段。拼接不重复镜头，也不与其他展示位置复用，不靠频繁切换本身冒充精彩。

选择时同时看版本、清晰度、干净程度、连续性和气势；不为了长而保留空景、无关镜头或明显拖沓画面。合理补搜后只剩明显受干扰或观感普通的候选，才采用后备并简短说明；几个精彩短段属于第二优先级，不能一概称为低级兜底。上述偏好用于真实选材及现有S/A/B/C评档，不增加专用验收表、哈希或媒体数学检查。

## 四档，按最终呈现逐级选择

| 档位 | 具体标准与用途 |
|---|---|
| S 首选 | 版本正确、无额外水印、画面干净清楚、人物鲜明且符合位置的优质原生动态；长展示先比精彩程度，同等精彩才优先连续长段：影视、动画、CG、宣传片，或达到相应观感的优秀实机 |
| A 优质替代 | 版本、构图和观感良好，作为当前用途的合适替代；视频持续展示按上述六级顺序比较，不把图片文件固定排在合格普通视频之前 |
| B 普通可用 | 身份版本正确、画面清楚，但气势、构图或动作表现普通；高档没有合适候选时采用 |
| C 最后兜底 | 主体仍可辨，但视角、人物分量、干扰或质感明显拖累观感，例如普通峡谷俯视实机；合理定向补搜仍无更好素材才采用 |

人物／版本不符、主体根本不可辨、伪造或无法满足明确配置的素材排除，不用“低档”掩盖身份错误。样本中的水印、黑边、二创模糊并非必须复制的优点；不要靠堆震动补救糊脸。

每个实际候选只需记**档位＋适合用途＋一句理由**，沿用原来的版本、来源和时间段记录即可。不建立数值评分表、专用验收回执或必须填满的新表。没有实际看过的素材保持待看，不自动评成S或判差。

工程编排现在实际消费这些选片结果。候选沿用`role/trimIn/trimOut/qualityTier/qualityReason`；需要区分方案时提供`excitement:exciting|ordinary`、`continuous`、`motion:native|animated|still`及`allowSlowdown`，它们是选片判断而非评级证明。原始文件改名/裁切/变速后用`sourceId/sourceIn/sourceOut`标明实际出处区间，编排器可据此避免跨用途重复。多段长展示直接给多个候选，不必先外部拼成一个MP4；不要把已有蒙太奇假标连续长镜头。缺口按角色、用途和缺少时长返回，只补相关素材。细节见[视频编排](video-editing.md#实际候选编排与缺口处理)。

## 按镜头划入出点，不能只看中间一帧

选段时先看前后相邻镜头，再连续看所选区间：从主体动作起势到落点，确认首帧、尾帧与内部切镜仍服务于该角色。发现快速切镜、遮挡或主体切换时，缩小时间步长查看边界，必要时逐帧确定入出点；不要按整秒凑长度，也不要让上一镜尾巴或下一人物特写混进来。需要补长度时换合适短镜头或优质图片动效，不拿无关画面填充。

对手可以作为交锋对象同框，判断重点是画面是否仍以目标角色为主体、装备和动作是否可辨。切到对手独立特写、远离目标的反应镜头或另一段剧情，须拆开另用；不能把其继续挂在目标姓名、属性或胜者页下。S/A/B/C评价针对**实际采用的区间及用途**，不将整部优质CG一并评成S。

把干净区间裁成可复用片段，或在工程中明确有效入出点；变速、循环、转场及目标画幅可能改变实际呈现，导出后还要看这些接点前后，避免回卷到选段之外、动作突跳、转场闪出其他人物。只需正常视觉复核：粗览全段定位内容，再对边界和疑点加密查看；几个代表帧不能代替首尾与内部切镜检查，不另建程序验收或评级回执。

## 搜寻与降档实际怎么做

1. 先查匹配配置的已有好素材。缺时按作品原名／别名、角色、演员／年份／形态加`cinematic / trailer / entrance / close-up / transformation / character showcase / key art / reference materials`，及相应中文／原文词定向找。游戏先查电影式CG、官方动画、赛季宣传和画师原作，不把技能演示页当作唯一入口。
2. 定位片名／场景后先找无水印干净高清源片；长展示按实际时长先找精彩长段，也主动比较几个精彩短段，不能为连续性压低观感。取得候选后比较取段，主动找脸、武器、核心、登场和状态镜头；按上面的镜头边界方法划入出点，再按实际用途评档。角色画面不足时同时搜官方原画、宣传图库及合适插画；不强制做无意义的全站遍历。
3. 在当前用途上比较观感与展示顺序。只有拖沓长段时，继续找精彩短段；不因连续、高清或无水印就提前收束。清楚的优质图片仍可优于明显较差的实机。选中足够精彩且满足用途的候选即可收束；“实在没有”是合理补搜后仍缺合适候选，不声称穷尽全网。
4. 找不到合适视频可用已有合适图片加动效。连可靠人物图也缺少时，按[稀缺角色素材](scarce-character-media.md)建立有原作依据的一致形象：优先接可用视频API／CLI，或由用户选择本地H3；无法采用动态生成时，制作多姿态／状态图片加动效。生成路线仍须择优，差生成视频不能压过清楚的图片动效。已有定型图的角色优先搜集，不把生成素材冒充原作截图。
5. 宿主有可用生图工具就按既有角色素材设计流程调用；没有时，直接询问是否安装本地生图模型、连接可用图像API或提供素材，由用户决定。不要无授权安装大模型、注册服务、付费或声称已经生成。

## 图片代替视频时的实际处理

用缩放／推拉、平移、轻微旋转、节拍震动、亮度或切换形成运动，强度按音乐和人物气质调整。比较底板适合稳定缓动，高光可在切点短促冲击。保留主体和脸部，不把整个画面永远剧烈摇晃，也不因图静止就降低其构图与气质价值。

需要分层或景深时必须有可用的层或抠图，不假称单张图已经有真实三维运动。普通动效不虚构新动作、招式或原作实绩。剪辑工程的图片片段可直接承担上述用途；已排除素材不参与自动选取，已评档素材优先于待看素材；比较底板固定，单项揭晓可在精挑的不同S/A候选间轮换，不为凑数加入明显较差画面；其他用途在兼容候选内优先最高档。

## 已研究的可迁移经验

九条参考片反复用凝视、微笑、红眼、利爪、骷髅、宝石装甲及站姿呈现人物；长动作更多在开场或结尾。V09多个属性共用同一祖国人近景，V06以火车头竖拇指和休伊紧绷表情区分性格；V01／V02使用绘图式画面也能有效展示角色。

因此不要把“每页新镜头／每页放对应能力实演／每个人都暴怒／优质必然是爆炸大场面”设为默认。学习角色呈现与片段位置的功能，保留对其他风格的选择空间，不照抄参考片给分或限制后续视频只能长成一种样子。
