# 视频维度的实际研究与双方比较

按需加载：只有选中的视频展示项超出已有报告，或原报告不足以支持双方排序时才补查。沿用独立评级与普通PK的原作搜证、可靠设定、关系传播、反例和缺口补链；数学与物理量继续严谨，定性表现也可在上下文充分时支持明确主估。固定九维保留，视频原标签不扩张为所有人物必须填写的新表。

## 执行顺序

1. 先复用配置匹配、当前有效的独立评级／普通PK。只有独立评级时继续普通PK；故事里的胜局、作者指定结局和为了叙事安排的信息优势不作正式视频依据。故事所保存的原作资料与合格独立评级可复用。
2. 将预选展示项改写成可比较的问题。区分独立属性、复合项、事实、综合结论和主题／梗；原参考片的给分仅作时序示例。维度数与音乐互相适配，不用同义词凑槽。
3. 先从双方已有档案找答案。缺的部分定向查动作、决策、压力、代价及结果，不只查“某某智商”；小说仍沿用拆书档案及指定时期／末期倒序取证。`research plan`请求可选`video_dimensions`，把这些问题接入现有研究任务和索引，非必用新入口。
4. 对齐双方任务与条件，写清各自支持到哪里、比较关系如何成立、重要反例怎样影响。优先同类任务／可靠共同参照，再用适用范围明确的交锋、排名、设定与有据综合推断。可靠的领域最强、同级和继承关系仍有作用；不因没有焦耳或重复实演就拒绝。
5. 给每个实际展示项一个有据结论与短理由。未知、未查到、真正相当、各有所长分别处理；遇到关键缺口先补查，不把未知记低、记0或随便判平手。复合项攻优防劣时拆页或写明各有所长，不任选一方。主题项不参与战斗投票。
6. 回到完整胜路，确定总胜者及下述难度。新增证据改变结论时更新上游分析；不为保住已选海报或音乐结尾漏掉反制。之后才把文案、单项揭晓者、总判和难度交剪辑器。剪辑器不证明原作命题，也不重跑评级验收。

`scripts/video_dimensions.py`覆盖9条参考视频的42个原标签，并提供别名归并、复合项拆解、主题／事实识别及定向任务。`research.py`的普通九维规划不变；提供视频标签时才增加对应任务，覆盖报告也能列出额外属性。其任务不是自动研究结论。`dimension_definitions`可把“技能”等含混标签指向当前实际采用的具体方法；不能通过改定义偷换已给出的原作事实。

别名表不是能力白名单。未收录的新标签由宿主先定义比较命题，再按任务、条件、来源与反例的方法处理；工具没有同名条目不等于无法评定，也不必为每个新词扩张核心九维。

## 力量与爆发

力量先定动作：举托、推拉、压制／角力、抓握控制或打击。核质量、重力、支撑、摩擦、加速、杠杆、持续与辅助能力；静态承重才适用相应的`F≈mg`。水平拉车不按车重直接排名，AP也不自动继承成握力。对齐共同动作或成立叠链，必要时复用功、冲量、扭矩与结构模型。力N、能量J、功率W分开；扭矩写N·m不等于已经做了同数值的功。

爆发先明确：建立力量／动作的快慢、短时间输出、临时增幅还是一招全力。依次查起始状态、准备／增幅、发挥多久、实际作用、复用与后续代价。峰值、起效速度与维持时间分开；有据倍率可用，剪辑长度不当世界内时间。只有对应能量与释放时间可靠时才算`P=ΔE/Δt`，W不填进J的档位。

## 速度与敏捷

区分感知、反应、身体动作、移动、攻击传播和出招／连击频率。预知、提前瞄准、传送或相位通过不自动变为身体反应。敏捷另看变向、急停、重心转换、避障、狭小空间调整及落地衔接；有可信尺度和时间才估相关加速度。合写“敏捷/反应力”不等于这些能力相同，拆页要有实质不同的比较。

## 耐力、耐伤、恢复和体质

耐力／续航对齐“何种强度、连续多久”：核停歇、躲避、补给、资源、冷却、功能衰减与恢复。三天低强度行动不自动胜过一小时高强度作战；无限能源也不表示结构、技能和承伤无限。

耐伤核伤到哪里、剩余功能和还能做什么；恢复核对象、程度、时间与代价；疼痛耐受先确认有痛感。大体型、HP多、硬防、无痛、再生和资源独立归属。非生物／非实体先查失能与资源机制，不硬套人类生理。

“体质”先说明是结构、耐伤、恢复、环境适应还是生存需求，优先改成具体名称。保留综合叫法时说明组成与本场重要性，不造万能身体总分，也不额外再给一票胜率。

## 智力、战斗智商、经验与技巧

- **智力**：确定领域与任务，重建信息／资源限制、独立解法与结果。研究、计算、记忆、学习、策略可各有优势。学历、IQ台词、科学家身份与同叫天才只是线索；被动知识、AI代算、预知、权限读取与本人推理分别归属。
- **战斗智商**：知道什么→面对何约束→如何试探／诱导／取舍→执行→对方反制→如何调整→结果。查距离、资源与情报管理；胜利、独白多、提前知道答案不直接证明更高临场推理。关键失败与学习同样查。
- **经验**：有效训练与实战、对手／机制／环境广度、独立程度、近期更新与迁移到本场的作用。寿命／击杀数不直接排名。复制经验或记忆可计入，但核理解、检索与实际运用，不自动精通所有技巧。
- **技巧／近战格斗**：从具体交手分辨距离、时机、平衡、路线、骗招、防守、擒控、兵器与学习贡献。核属性、构造、人数、装备、情报与地形，不把纯碾压当技巧，也不虚构同属性实战作证。

这些能力可以互助，不能直接互叠。找到可靠共同参照或适用设定后，可给合理综合主判；不能因为没有统一IQ公式就一直不判。“技能”先定指技巧、特能还是组合，再走对应方法。

## 心理素质、勇气与威慑

心理素质追具体压力：痛苦、恐惧、受挫、失去优势或信息突变，随后判断／执行怎样变化，能否维持、恢复、有无反例。冷脸不是稳定证明，愤怒不自动丧失战术，一次错误也不定义整个人物。

勇气追知道风险后的目标、选择、代价及真正存在的恐惧／痛感；不把无知、无痛、失控或缺乏自保机制自动判勇敢，也不把战术撤退判胆怯。

威慑先分观感／声望、对象理解真实威胁后的行为和超常恐惧。查对象为什么退缩、是否知道身份、其他动机与反例；普通人恐慌不自动影响本场强敌。超常威慑按所选特能规则审对象、范围、影响上限与抗性。自然品质不自动构成高层精神或叙事抗性；画面有气势也不自动是论战威慑实绩。

## 武器、技能伤害、杀伤与弱点

先定具体一招／技能组／装备与本场目标：发动→命中→穿过相关防御／抗性→作用／失能→持续与代价。剥离偷袭、特定弱点、环境连锁及非本人贡献。控制、封印、删除、转化、降格等无J作用仍有效，但机制作用不自动成为同档拳力。杀伤依赖目标，爆炸范围与击杀数量不直接决定本场终结能力。

武器核所选时期实际持有与形态，再看效能、距离、操控、消耗、冷却、可靠性、损坏／失控及对方反制。性能、本人使用水平与本场威胁分别说明；材料名称、传说与名气不直接给具体威能，可靠设定与实绩则照常采用。

弱点继续追到：能得知→能制造或接近条件→能执行→确有作用→能完成胜利。不能默认开局全知；曾被某材料伤不表示任意同名材料、任意施力皆有效。输出、杀伤、技能伤害、破坏只有实际含义不同时才分别上屏，不重复算票。

## 事实、主题、复合项与总判

年龄是事实，不自动等于经验。野心、真实、正义、人气等是主题／梗，需要各自清楚含义与依据，不当通用战斗统计；“月牙天冲”若实际指一招则另定义为技能作用。优势／全面是决定因素的概括，不是独立一票。“完胜”属于总体结果／难度表达，不能从字幕直接导出。

正式视频必须有总胜者与获胜难度。复用或执行[普通PK](matchups.md)的双方完整胜路与最强可行反制：先综合量级，再核速度、有效攻击、防御／抗性、发动、装备、状态与明确例外。保持所选汪吧／VSB规则，不能靠赢项数推总体胜负。确实未决时继续查关键缺口；真正平局不伪造胜者，本胜负视频格式暂不交付虚构的胜方。

## 获胜难度：五档

先定通常条件下的优势方，再研究**对手有效威胁、应对／反制压力、受伤或失能风险、资源／状态代价、终结窗口和胜路稳定性**。根据其组合给一个难度主估，关键前提或相邻档争议留在报告。没有统一加权分数，也不按维度票数或单次伤口机械换档。

| id | 中文／英文显示 | 判定依据 |
|---|---|---|
| no | 无难度／No Diff | 正常执行胜路即可，对方难以形成有效干扰或实质威胁，没有明显战斗代价；不要求一定秒杀 |
| low | 低难度／Low Diff | 需有意识应对，局部攻击／干扰存在，但可控，通常资源即可完成，稳定性高 |
| mid | 中难度／Mid Diff | 对方有实质可行威胁，需要有效战术与反制，付出有意义代价或承受明显压力，但不主要依赖极窄险胜窗口 |
| high | 高难度／High Diff | 多次严重失利风险、较大消耗／损伤或强反制压力；需要正确执行关键战术与窗口，明显缺少容错 |
| extreme | 极高难度／Extreme Diff | 胜局持续接近失败边缘，依赖很窄的关键窗口或接近极限的资源／执行，微小失误可改变结果 |

心理、信息、时间窗口与机制压力也能构成高难度，不强求肉体重伤。一次瞬杀仍可能需要非常艰难的发动窗口；打得久也可能全程无实质威胁。难度与胜率分别论证，极高难度不自动等于五五开；不能用专门编写的一局故事把难度压低，也不能为炫技强行提高。

先把足以影响档位的缺口查清，再用有据的合理主估落一档。报告保留难度理由；视频尾段采用“胜者姓名＋难度”两行，字号接近，语言跟随用户。胜者与难度不能被片尾水印或可选配文替代。参考演示不是正式研究，允许显示“未评定（演示）”，不假造难度。
