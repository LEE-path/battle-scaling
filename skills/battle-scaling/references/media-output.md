# 媒体产出：PK 结果一图流

先执行[媒体审片与返工铁律](media-review.md)的本次内容边界、实际构图与成图复核；求饶贴图属于本类型约定，不带到未要求它的海报里。

缺角色图片时加载[角色媒体搜寻](media-sourcing.md)：按本场版本搜多个候选、取得原图并实际选图，再沿用本页拼贴；不把搜索缩略图当唯一素材。

本页是一图流的独立娱乐媒体制作指南。只在用户明确要求“一图流”“论战圈你不得不承认的事实”或类似成图时调用；完成评级或 PK 后不自动出图。用户要求PK海报／视频封面时，改用[PK海报与封面](pk-cover.md)及其随包模板，两种版式分别按需调用。本页处理静态一图流；属性比较卡点视频使用[本地视频剪辑](video-editing.md)。

## 与评级及对战的关系

直接使用本场已经确定的胜者、败者、配置和显示名。若用户同时要求判断胜负，先走原有评级／PK 流程，再来制图；已有结果就不重复评级。条件结论沿用用户选定的分支，没有选边时简短问清即可。

媒体娱乐产出不进入数学核算、评级门槛或程序验收流程，不要求提交评级包、JSON 契约、调用回执、哈希或验收字段。后续其他娱乐媒体功能也遵守这个边界。图像只表达已有结论，不反过来作为量级、能力或原作表现的证据。

## 默认版式

- 白底，**胜者左、败者右**，中间放醒目的 `>`。
- 顶部默认写 **论战圈你不得不承认的事实**。用户可改标题，可选在标题后加 `😂`。
- 水龙求饶图**优先刚好铺满败者脸部；只有确实无脸时才贴核心位置**。按目标脸部／核心的实际范围和朝向缩放，必要时旋转，覆盖原脸主体；不沿用固定尺寸贴纸，不贴得过小，也不扩大到遮住大片身体。贴后仍保留角色轮廓、服装或武器供辨认；有脸不能为了好贴而改贴胸口、武器或其他部位。
- 败者一侧下方配文 **{胜者名字}{爸爸／妈妈}我错了**。明确女性用“妈妈”，其他默认梗称呼“爸爸”，用户指定优先；不靠看脸推测性别。
- 标题、主图和底文清楚，留白接近用户参考。长名字可缩字或换行，不能截断。画幅可调整，不额外塞入评级表、长解释或无关标识。

## 制作流程

1. 从已有 PK 结果取胜败和名字。为双方搜集多张对应版本的人物图，视觉比较后择优，而不是拿到搜索首图就使用。重点比较角色／服装与配置、辨识度、清晰度、姿态朝向、背景及裁切难度、版式适配，以及败者被贴住脸后是否仍可辨认。可优先复用已有合适素材和备选，不为选头像重跑评级搜证；候选数量依实际需要，不把选图变成程序门槛。
2. **优先使用用户提供的独立水龙求饶原图**，已有干净原图就直接复用，不再从示例拼图裁切。保留原文件，裁切或去底只做工作副本。
3. 有明确人物图像就直接用于拼贴；找不到明确形象时，先按下节从原作外貌描写设计并生成人物素材，再拼贴。生图只补角色素材，不制作整张一图流，也不用于给既有人物换脸或融合水龙表情。
4. 定位败者实际脸部；无脸时定位核心。按该区域大小和朝向贴合水龙图，优先铺满，必要时缩放、旋转；以最终成图看覆盖范围，不能只凭默认坐标。确认胜左败右、人物与名字对应、中文清楚、求饶表情可辨且未遮住大片身体；不合适就改贴图或人物素材。交付图片即可。

**SCP角色选图**：优先从[SCP艺术中心](https://scp-wiki.wikidot.com/artwork-hub)及站内画师作品集按项目编号和名称找图，默认优先高对比的黑白版画风、剪影或线刻作品，不限定画师。比较多个候选，优先主体清楚、特征鲜明、贴脸后仍能辨认的图。站内艺术区没有合适作品时，可选原条目收录的黑白插画等相容素材，并如实说明出处；不把其他项目的画借来充数，也不把普通彩图去色后冒称原版黑白作品。用户另定风格时服从其要求。画师图用于视觉表现，不因此成为角色唯一官方定型或能力证据。

这一步是轻量的**视觉复核**，不是评级审查，也不需要制作专门的回执或证明文件。不要因为一张娱乐拼图再次启动全项目测试、数学检查或评级验收。

## 缺少明确人物图像：先按文字设计角色素材

生图只在没有明确人物图像可用时补充角色素材，例如没有稳定视觉定型的小说角色。已有漫画、动画、影视或其他明确角色图时，优先搜集适配的现成图，不因角色冷门就直接放弃搜图。墨穷若已有合适漫画图，应走现成图路线；蓝牧、白歌可作为本次按文字设计的试用例子，不预设他们永远没有现成图。

- 定向查原作中本人在相关形态／时期的外貌、服装、身材、神态，以及代表能力的发动方式、标志性装备／持有物和典型行为。优先复用已读档案，必要时联网补找。看上下文确认描写对象，不能把他看见的人、临时易容或其他变身形态套成本尊。
- **让人物的身份和力量有可辨认的视觉表达**：不要止步于发色、衣服和普通站姿。选少数最能代表此人的特征组织构图，让神态、姿势、能力作用对象及装备共同说明“是谁、怎样运用力量”。压迫感可以来自冷静、尺度对比、精确控制或行动后果，不等同于堆叠星空、盔甲、王冠和光圈。不同人物应有不同的轮廓与能力表现方式，缩小后仍能辨认。
- 装备须区分本人持有、借用、他人物品及已失去的物品；核对所选时期是否仍能使用。不为补视觉而添加终极武器，也不把伴生意识画成一件同名实物。若用曾持有的器物作人物经历意象，在素材说明中说明，不当作本场已携带的装备或末期力量来源；明确要求还原当时战斗配置时，只画当时可用的内容。
- 保留原文明示的特征；五官、发型、具体服装等没有明确写出的部分，可作相容的视觉设计，并注明是补完。抽象能力允许用易懂的视觉比喻表现，但应关联其实际作用与操控方式，并说明是插画化表达，不冒称原作固定特效、永久身体特征或新的能力。不要冒称官方定型，也不从所画形象反推角色能力。
- 只生成一张便于拼贴的角色素材：轮廓清晰、姿态适合左右对比、尽量透明背景、没有额外文字。人物样式以所选作品和用户偏好为准，不因例子固定成同一种衣服或画风。
- 把生成的人物素材与其他现成人物图一样交给下节排版。模型不参与胜负、整图排字或水龙表情融合；既有水龙原图直接贴用。

可替换的人物素材提示词：

```text
生成单个人物素材，用于之后的图片拼贴，不制作海报或比较图。
角色：【{名字及作品}】；本次形态／时期：【{配置}】。
原作已明确的外貌特征：【{外貌、服装、体态、神态}】。
代表能力与原作呈现：【{作用对象、发动方式、可见特征}】；本图重点展示：【{少数最有辨识度的视觉特征及手势}】。
装备／持有物：【{名称、外形、时期与归属；无适合者则省略}】。
抽象能力的插画化表达或经历意象：【{有依据的机制如何画出来；与当时实物配置区分}】。
原作未明确、仅为本次视觉设计补完的细节：【{补完项}】。
请保留已明确特征，采用【{画风与姿态}】，人物完整可辨，边缘清楚，透明背景。
不要添加标题、文字、水印、其他角色或未提供的装备与特效。
这是一份基于文字的自行设计形象，不作为官方角色定型。
```

## 统一成图：素材拼贴与排版

使用图片编辑工具，或可选的 Python／Pillow 辅助脚本。将现有素材缩放摆放，叠加水龙图，再排标题、`>` 和底文即可；无需模型权重、API Key 或评级工具。

```powershell
python scripts/one_image.py --winner "winner.png" --loser "loser.png" --winner-name "胜者名字" --output "一图流.png" --surrender "水龙求饶图.png"
```

按需追加参数：

- `--title "自定义标题"`：替换顶部文字。
- `--address "妈妈"`：替换称呼；默认“爸爸”，由 Agent 按已知角色信息选择。
- `--emoji`：在标题后添加 `😂`。
- `--font "中文字体路径"`：使用可用中文字体，避免方框字。
- `--face-box x0 y0 x1 y1`：指定败者原图中实际脸部／核心范围，坐标为0～1相对位置；按目标选大小，不是固定贴纸。工具保留的省略默认值仅兼容旧示意，不是自动识脸，新图须实际定位后设置。
- `--face-angle 度数`：可选，按顺时针角度转动水龙图，默认0；围绕目标框中心旋转以贴合人物朝向。旋转后目视调整框大小和角度，让贴图刚好覆盖脸／核心而不侵占大片躯干。

素材与字体按需取得，不默认将用户图片、漫画贴图或系统字体打进公开技能包。若已有水龙默认素材，直接复用；缺少时再取用户已提供的图片或寻找对应素材。
