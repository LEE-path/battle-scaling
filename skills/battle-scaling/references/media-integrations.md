# 扩展素材搜集与图像／视频生成后端

用户可以导入GitHub项目、压缩包、本地项目目录、API文档、MCP服务器或CLI，扩展媒体搜索、下载、提取、图像生成、视频生成及后处理。宿主按本页实际接入；本页不声称任意项目天然兼容。此模块按需调用，独立于评级取证、数学验收和故事裁决；外部工具取得的素材仍按[用途与选材](media-selection.md)挑选。

## 从用户提供的项目到可调用工具

先读取项目说明、实际入口和必要依赖，弄清它能做搜索、取得原文件、提取页面内媒体、图库批量取得、生成，还是只提供索引／预览。确认支持的站点、输入输出、登录或费用条件，以及本机是否已有可复用安装。不因名字含“全网／下载器／AI”就认为上述能力齐全，也不把方法借鉴等同于项目已经接入。

用户给出本地目录时优先检查和复用；给出仓库／压缩包时按用户授权范围取得所需源码，保留上游来源与适用许可。实际需要时才安装依赖，不把模型权重和大型测试数据混进Skill。已有获准的安装或调用不反复确认；新出现的收费、账号登录、大模型下载或范围外系统修改，先把需要用户决定的具体选项说明白。

优先保留项目原接口，仅在输入输出确实不兼容时写薄适配：将用户的检索词、作品／角色版本或参考图交进去，取回真实文件及来源。不要为了“统一接入”重写项目、强迫所有平台采用同一种协议，或建立没有消费者的配置字段。

## 不同接口怎样绑定

| 接口 | 需要实际落实的部分 |
|---|---|
| API／SDK | 平台／模型、官方端点与请求格式、认证、图像／视频参考上传方式、异步提交／查询／下载；有额度或费用时沿用用户已授权范围 |
| MCP | 确认宿主已加载服务器并实际出现所需工具，读取工具说明后调用；仅写入一份MCP配置不等于当前Agent已经连接。宿主需要用户完成连接时明确交代该步骤 |
| CLI／本地服务 | 实际可执行文件或服务地址、运行目录、环境、参数与文件输出；先用`--help`或文档确认用法，不靠窗口自动化代替已有命令接口 |
| 本地模型 | 核对模型、任务类型、运行器、硬件兼容与权重／处理器等必要组件；明确下载盘、环境、缓存和输出位置，再按用户选择下载并真实生成 |

生图和生视频可以绑定不同项目或平台，也可以分别使用远程API、MCP、CLI或本地模型。优先复用宿主已经连接且可用的工具；只有缺少必要信息才逐项询问，不要求用户一次填写整套问卷。密钥沿用私有凭据或环境变量，不写进提示词、任务素材、Skill静态文件和公开包。

## 本地模型下载与使用

支持下载并使用用户选择的图像／视频模型，H3是一个可选视频后端，并非唯一后端。选择前按当前具体版本说明系统／GPU兼容性、显存、内存、权重下载量、完整环境与缓存的磁盘预留、可能的耗时及已知未验证项；区分文件大小、下载临时占用和最终占用。H3的现有有据参考见[稀缺角色素材](scarce-character-media.md#h3配置说明的有据参考)，其他模型查其当前官方说明，不套用H3数字。

优先隔离环境、复用相同权重与已完成下载，不重复下载所有精度或任务分支。按本次任务下载必要组件；下载完整不等于已能推理。用真实需要的输入类型生成一个小样，确认文件有图像／视频内容、角色参考有效、清晰度和耗时可接受，再用于本场素材。未跑通就说明实际缺口，不把“安装成功”包装为稳定产出。

## 接入后的轻量留档与复用

将本机绑定说明放在使用者的私有运行配置或可选`runtime/media-integrations.local.md`中。用简短自然语言记项目／模型、上游地址或版本、实际入口、凭据引用方式、输出目录、已实测功能和限制即可；已有同等配置不再建立副本。运行配置不随Skill公开同步，也不覆盖宿主既有工具设置。

首次接入按实际用途试一次有代表性的检索、取得文件或生成；记录取得了什么、哪些能力仍未验证。此后状态未变直接复用，失败或版本变化时只复核相关环节。搜索只返回链接、能下载文件、能够解析人物，以及生成文件可用，是不同能力，记录要与实际结果相符。

媒体搜集的新站点／检索与提取经验继续进入[媒体经验记录](media-sourcing.md#轻量积累与复用)。生成素材继续遵从[统一形象与兜底](scarce-character-media.md)、本场状态／装备和揭晓辨识门槛；绑定新模型不会改变这些标准。后端不可用时换已配置后端或按既有图片动效兜底，不让安装或反复重试吞掉整场制作。
