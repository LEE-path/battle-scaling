# 原作沉浸与跨体系战斗写作

当写作任务涉及已有作品角色，且作者希望“像原作中的他们在战斗”，按需加载本页。它补充 [战斗写作辅助](writing-battle.md)，不改变作者指定设定、结局、冲突处理或研究版论战规则。纯原创角色以作者创作卡为依据，不强制寻找不存在的原作。

目标是让角色的选择、招式发动、交锋节奏、语言和战后处理都能被辨认。不能只换角色名、口头禅和招式名，沿用一篇通用强者打斗。原作沉浸依靠高层叙事技法和有依据的行为特征；保持新场景与新措辞，不逐句复刻原文，也不模仿在世作者独特的表达指纹。

## 六步工作流

`固定版本状态 → 完整内部评级／合格档案复用 → 原作写法取样与两份画像 → 体系交互与因果节拍 → 文学正文 → 人物／量级／终局复核`

先按[写作内部评级](writing-rating-baseline.md)验收双方所选配置的九维量级与能力实绩。已有完整、已验收且配置匹配的档案可复用并补查变化；无合格档案的小说角色优先论战拆书，不因“故事版”跳过。下述针对性取样解决人物与写法，不能替代完整评级，也不能以“以前研究过能力”代替本次核对。原创与作者明确改编的部分依据其设定形成同样的能力底稿，不伪造原作出处。正文仍不附研究报告。

取样按[故事版文字取证边界](writing-rating-baseline.md#故事版取证边界)执行，优先已有档案、原作文字／官方文本和可靠资料，不强制新增读图／抽帧。少量针对性取样足以指导本篇时进入创作，不以更多素材数量代替文学打磨。

### 1. 先找实际场景，再归纳特征

为每位已有作品角色选择少量与本篇有关的代表场景。按情境补样，数量不等于质量，不机械规定几章算读懂人物：

| 要解决的问题 | 优先读什么 | 应提取什么 |
|---|---|---|
| 为何到场并介入 | 当前时段剧情、出行与跨界实绩、日常目标及遭遇陌生事件的实例 | 到达手段、世界通行边界、当时所知、风险判断、介入理由及其与后续行动的联系 |
| 此时会怎样战斗 | 同时期、相近任务和敌情下的实际交锋 | 开局选择、试探方式、情报来源、升级条件与放弃某招的原因 |
| 技能怎样发动 | 技能首次解释、成熟用法、被有效反制的场面 | 真实前置、动作与媒介、内外部可见信息、效果落点及后续代价 |
| 为什么这样说话 | 日常、认真交战、危急处境等不同语境 | 语气、句长、称谓、幽默、沉默、对敌我信息披露的差别 |
| 怎样对付未知强敌 | 遭遇信息不足、规则异常或不可信对象的场景 | 是否试探、远离、分身、备份、抢攻、谈判、调查或先控场 |
| 怎样处置败者 | 放过、俘虏、杀死、解除能力、收容与追查来源的实例 | 决定条件、底线、剩余风险和确保结果的措施 |
| 原作怎样组织战斗 | 本角色或同体系的完整战斗段落 | 镜头与视角、动作／判断／对白比例、冲击与停顿、伏笔和收束方式 |

为每条重要结论保留具体定位：作品、版本、章节／集数／页格／时间码、角色当时状态和一两句归纳。原作场景、作者明确陈述、可信二手资料与宿主解释分开。搜索摘要、粉丝印象、角色标签和出场音效不能单独证明关键能力或处置习惯。

“豪放”“谨慎”“温柔”“冷酷”只作索引词。把它改写成条件化行为：面对何种对象、为了什么目的、知道什么、承担什么风险，实际采取了什么行动。例如研究悟空时可以关注大幅度近身交锋、对手强弱判断、提升战斗烈度与交流的关系；不能从“喜欢战斗”推成所有版本、所有危机下都礼让对手、蓄满力量或拒绝速胜。对家人、平民、比赛对手与灭世敌人的决策差异，需要由对应场景支持。

若缺少会决定本篇结局的原作事实，先按[缺口补链](evidence-gap-recovery.md)主动扩查相关实绩、共同参照和可用模型，匹配机制、出力、部位与状态后推断。缺同款镜头或未命名材质不是停止理由；推断充分即可采用，不全归为创作假设。穷尽有用补链后仍存在关键不可解冲突，才保留真正未决项或请作者确认，不偷偷把最方便的解释写进人物原有能力。普通的灯光、天气与不改变战果的感官细节可以自然创作。

### 2. 分别建立人物与体系画像

两人各自先成卡，再合成一场战斗。不要让败者只有技能清单、胜者才有人物动机。

没有交战前因时，按 [自动补足交战前因](writing-battle.md#自动补足交战前因) 从双方画像和当前处境设计入场、相遇与冲突，核对到场手段、世界边界及人物判断，先确认二人为何会介入、接受、继续或升级交手，再安排招式。范例只借鉴设计方法，不代替本场的选择理由。自编前因只属本篇创作；不能为让他们打起来而更改原有人设，或借背景暗加决定性情报、备战与能力。

**人物画像必须能够指导动作。** 记录当前目标、不能接受的损失、对陌生人的初始态度、获得情报的方式、可承受风险、升级阈值、敌人认输是否足够、战后会核对什么。区分一贯行为与当前疲劳、创伤、任务、愤怒、信任关系造成的变化。能力最高时期不自动代表情绪最冷酷、战斗最熟练或一开始就全知。

**语言与叙述分开。** 角色自己的对白包含称谓、措辞、停顿、玩笑和是否暴露意图；叙述包含焦点、距离、节奏、描写对象及何时解释能力。统一叙述者也可以容纳两种人物语言。不要让所有角色都说判词、给技能讲课，或靠每段点一次口头禅证明人设。

**人物基调进入事件组织。** 按[角色基调、第四墙与喜剧因果](writing-tone-and-gags.md)，在既有六轴画像中记录幽默、风险态度、媒介认知和表现习惯怎样改变观察、出招、失误、转折与收尾。死侍的元认知、卡通角色有依据的变形与恢复等要实际参与本篇，不只作为台词装饰；同时保留对方的独立声音、完整评级和真实能力边界。整体节奏可以改变，不要求所有人物一起变成喜剧演员。

**技能的写法来自实际使用过程。** 对关键招式记录：

`意图 → 准备／载体 → 可见或不可见的发动 → 对手察觉什么 → 实际作用对象 → 生效反馈 → 代价与下一次使用条件`

有些能力以大动作、蓄力与外部威压体现；有些依赖隐蔽设置、目标辨识或信息操作。后者可以通过观察、目标选取、动作落点和异常后果写清楚，不必强加发光阵法或高声报招；前者也不能因节省篇幅省掉原有准备。将本来难以直接目视的机制写成可理解的后果，不能凭空增加“所有人都能看见权限线”等感知能力。

**力量体系有自己的战斗语法。** 从所选作品提取以下内容，只选会进入本篇的部分：

- 常见的攻击媒介与感知方式：拳脚、武器、能量、术式、精神、信息、叙事等，哪些能直接观察，哪些需要试探。
- 局面的组织方式：距离争夺、连续追击、破绽、招架与卸力、范围压制、领域／结界、规则解明、先设条件再收网等。
- 强弱如何显现：速度与力量差距、无法破防、读懂招式、耐力衰减、媒介被破坏、规则优先级等。不能把所有差距写成更大的爆炸。
- 典型的节奏与升级：短促动作和高速连续交手、蓄力与对波、交错调查与局部兑现、规则逐层暴露、形态变化或代价递增等。
- 失败怎样发生：身体受创、失去行动功能、资源耗尽、条件无法完成、控制权转移、目标被夺走或任务完成。击倒、杀死、封印和放弃战斗分别处理。

这些是可变的编排材料，不是每场必须凑齐的固定流程。所谓“原作经典感”来自能力与人物怎样共同改变局面，不能只堆原作名词和招式播报。

### 3. 逐点设计跨体系交锋

不同体系的新意应出现在**双方为了对付对方而改变了什么**，且改变之后有后果。先选少量真正决定胜负的交互，内部写清它们的成立条件，再写入正文。

对每个关键交互检查：

1. **发现与接触**：攻击者怎样发现、定位或接近目标？对方能看到发动本身、只能看到结果，还是有合法的察觉方式？
2. **作用层与媒介**：作用于肉身、装备、能量、精神、因果、信息还是故事表达？攻击路径有没有经过某项防御的真实作用范围？
3. **发动与兑现**：准备、释放、命中、产生效果和持续维持各自需要什么？对手能破坏哪一个阶段？
4. **抵抗与响应**：已有抗性覆盖什么对象与机制？防御失败后，能否改目标、切媒介、让出空间、牺牲资源或完成另一项任务？
5. **恢复与终局**：被击中之后还能行动、转移、修复或重启吗？怎样确保达成作者给定的胜利条件？

不默认所有能量互通、能看见灵魂就能看见信息、叙事角色就免疫一切信息操作，也不把同样叫“空间”“无限”“绝对”的能力直接视作同一层权限。量级不替代作用机制；相似机制也不自动给出无条件抗性。

先按 [控制、认知与抗性](writing-battle.md#先结算控制认知与抗性) 确定生效后的状态，再排反应。作用覆盖与对应抗性已经核清，或作者已经明确固定本篇关系时，必须兑现结果；不能为了体现智谋或延长交锋补回已失去的清醒与自主行动。角色保持性格，不等于免疫人格、记忆或叙事身份的改写。

跨体系选择分三类记录：

| 类型 | 内容 | 使用边界 |
|---|---|---|
| 原作依据与有据推断 | 已核的能力、动作、限制、反制与人物选择；由这些前提形成、单独留有比较桥的交互推断 | 直接事实与推导分开，定位到所选版本，不能由标签外推新权限；不要求原作已直接演过同一跨作战局 |
| 创作交互桥 | 本篇对两个已有机制如何接触、表现和结算的固定选择 | 不能添能力、抗性、覆盖范围或新发动媒介，也不能推翻已定压制与认知状态；不能临近结尾改写 |
| 作者覆盖 | 作者明确更改的人设、能力、条件、世界规则或结局 | 只属本篇改编，按作者授权范围使用，不回填原作证据 |

例如已有两项感知能力如何在同一个场景中呈现，可以固定一个一致的接触关系；若解法需要原作从未具备的“将对方所有权限复制到自己身上”，那是新增能力，不是交互桥。保留设定时找其他现有手段；确有硬冲突，回到 [冲突处理](writing-battle.md#指定结局与硬冲突) 询问作者。

让体系摩擦产生可见的战术变化。可选方向包括：

- 一方的高速连续攻防，迫使依赖准备的一方把准备藏入位移、诱饵或先前环境中；具体准备必须本来可行。
- 一方用规则改变局面，另一方通过已经掌握的感知和试探，发现作用载体或结算时点，再改选攻击目标；“发现”不自动获得解除规则的能力。
- 一方的叙述既是表现形式也是实际作用，另一方观察到叙述引发的变化，将其当作反馈；之后能否进一步操作，仍取决于其真实能力。
- 体型、射程或恢复方式不对称，使双方争夺受击部位、落点、资源与任务目标；不能只轮流报最强招式。

这些仅是设计提示，不是某两个角色一定能够互相克制的证据。对手仅在实际保留的认知与行动条件内回应；无法理解、完全入戏、反制失效或立即失能均可以是正确结果。条件允许时才安排发现线索、调整策略或迫使代价。强弱悬殊不强行制造势均力敌；完整故事可以展开受控身份内部的案件与冲突，不必延长外部能力争夺。

### 4. 用节拍把人物、体系和状态接起来

每个重要节拍记一行：

`当下目标／所知信息 → 选择与发动 → 对手回应 → 实际变化和代价 → 新的机会或风险`

补上两个用于本页的简短字段：`人物依据` 和 `体系碰撞`。它们可指向画像或交互编号，避免一张很完整的设定卡没有进入正文。并非每一拳都要绑定资料；关键转折应能解释为何是这两个人打出了这一局。

按时间推进状态与知识。试探得到什么，欺骗让谁错判，某个位置或媒介为何暴露，谁已看出而谁尚未察觉，均要有前因。读者可以先于一方知道伏笔，人物不能借叙述者视角获取情报。反向规划终局不等于角色提前知道结局。

已核的第四墙认知及作品、演员、观众等知识属于角色自己的信息，允许按原有范围使用，不能因上述禁令一概删除。认识虚构身份、实际掌握哪些信息、能否操作媒介或改写事件分别确认；这不自动赋予对方私密计划、未来动作、全知或控稿权限，也不绕过已经成立的认知控制。

资源、伤势、形态、情绪、技能共存与持续控制一起结算。体力下降应改变招式选择或效果；认真起来需要任务与反馈支持；曾被破解的技能可以换条件再用，但不能在后文无解释恢复成无解。同一大招重复而局面没有变化时，压缩篇幅。

### 5. 转成连贯正文

先选一个能容纳双方的叙述方案：统一的清楚叙述、交替人物焦点，或一种主视角中嵌入另一方具有实际作用的声音。切换应有场景、行动或感知锚点，不在一句话中混入双方未公开的心思。若交替节奏，只在有意义的局面转折切换，避免每一段换一种文体。

以动作、反应和结果承载战术，充分说明理解当前攻防所需的信息；原作张力与 [叙述清晰度](writing-battle.md#叙述清晰度) 一起满足。复杂信息战同样需要明确的行动者、载体、目标和前后变化。能力怎样使某个结果发生、反制怎样阻断它，须在读者需要时交代；不能只留下“更深的联系”“更高的权限”等词，让读者自行补全关键因果。完整预案可以后揭，当前发生的动作与直接结果应当清楚。保持原作常见的张力方式，同时让这场新交锋拥有自己的铺垫和回收。

人物语言服务于当时目标：试探、挑衅、安抚、争取时间、隐瞒、诱导或确认。严肃人物也可以有幽默；爱战斗的人也会速杀；理性人物也会因重要的人或任务冒险。避免把所有人写成句句精确的规则说明书。

按[篇幅与人物对白](writing-battle.md#篇幅与人物对白)让交流充分展开。原作感也包括人物怎样接话、表达不满与关切、回应反馈及把理由说明白，不能只剩称谓、口癖和冷淡短句。字数未限时，不以压短台词为默认美学；用符合角色认知的自然口语、动作及叙述保持可读，保留人物本来寡言或健谈的差别。没有必要靠人物讲课来补充可由叙述清楚呈现的信息。

华丽来自运动关系、力量介质、空间变化、感官对比及代价。一个已经埋下的细小动作决定终局，可能比一串不断增大的形容词更有冲击力。强力角色可以表现得压倒性；不能无依据抹除对手有效行为，但实际控制已完全覆盖时，应如实写出独立反抗的丧失。

正文不默认附引文、胜率、反例、条件表或创作免责声明。资料与交互选择保存在创作记录；作者要设计说明时给简短依据与关键铺垫，不输出私有逐字思维链。

### 6. 终局先完成任务，再检查人物是否会这样收手

战后处置属于战斗因果的一部分。胜者停手、杀死、俘虏、解除能力、交接或离开，都应符合其目标、底线与实际控制程度。不要预设温柔角色一定放走对手，也不要预设谨慎角色一定杀死未知存在。

按本篇真实相关性检查：

- 已达成的胜利条件是什么，败者的身体、装备、能力与行动空间分别处于什么状态？
- 还有没有本篇已有的持续效果、远端载体、恢复方式、隐藏行动或上游操纵者？未知风险如何被人物合理看待？
- 角色凭什么相信结果有效？对方的认输、一次技能失败、暂时安静是否足够，还是其一贯做法要求进一步核对和控制？
- 胜者能否在既有能力下维持控制，成本与责任由谁承担？不能凭空生成永久监控、全知证明或绝对牢笼来补结尾。
- 放过或杀死会影响什么关系、任务和后续秩序？现场身体胜利与真正解决问题是否一致？

将与本场相关的处置写到目的、执行与结果足够清楚，篇幅由内容需要决定，不预设动作或台词数量，也无需在正文末尾打印风险清单。若角色本来不关心某种风险，不强迫其执行另一位角色的处置程序。

## 最后四次审读

1. **去名审读**：暂时遮去名字与招式名，读者还能从目标、动作、语言和处置辨认人物吗？若只有标签可辨，重写关键选择。
2. **换人审读**：把两人换成另两个强者，战局是否几乎完全不变？若是，体系与人物还没有真正进入因果。
3. **败方审读**：败方的认知、可用能力与行动自由是否符合受控后的实际状态？仍有可行解法时是否合理使用，没有时是否写清为何失效？不强制败方造成伤害或改变局面，也不能靠遗忘仍有效的能力完成结局。角色身份内的行动不等于故事外抵抗。
4. **终局审读**：结尾是否只是胜者宣布赢了？实际战果、残留作用和符合人物的处置是否已在正文成立？有无为收尾临时增加控制能力、复活或未登场援军？

工具可核对资料键、节拍绑定、约束覆盖、先后与缺项，不能证明对白像原作、行为符合人设、交互在语义上可行或战斗足够精彩。宿主必须实际阅读全文并完成这些审读；字段填写和结构通过不等于已验收。

另做一次**清晰度审读**：以不熟悉双方详细能力的读者视角，检查关键段能否复述“谁做了什么、怎样生效、对手如何应对、局面如何改变”。读者答不出时，先补主体、动作或必要机制解释，再调整氛围与悬念；保留人物的误判，不让叙述者的含混替代误判。

补做**基调审读**：幽默、元认知或卡通表现是否改变事件的发生方式，而非仅插几句梗？它们的实际效果是否符合已核范围？另一方是否仍有自己的语气与决策？开局能否看清冲突，结尾能否看清谁完成目标及怎样结束？不以模仿原作氛围为由省掉这些信息。
