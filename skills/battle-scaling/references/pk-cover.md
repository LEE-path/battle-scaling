# PK海报与视频封面

先执行[媒体审片与返工铁律](media-review.md)，尤其是内容边界与真实版式审看。默认只排双方名字、必要版本短注、VS、所选分界和小Battle Scaling水印；不自行加量级/胜负标牌、口号、其他人物/署名、梗图或无请求的说明文字。用户明确指定的扩展设计优先。原图有多余文字/人物须裁去或换图，不能随素材一并带入成图。

双方图片／帧素材不足时加载[角色媒体搜寻](media-sourcing.md)，按本页构图需要取得并比较候选；既有优质素材优先复用。

用户明确要求“PK海报／对战封面／VS封面／论战视频封面”时调用。本模块只做独立媒体制作，接收双方名字、版本、状态、装备与已有题目；无需先知道胜败。用户同时要求评定或PK时，那部分按原流程完成，制图不重复启动评级、故事编排或数学检查。

默认成图为16:9横幅，1920×1080。用户提供新参考、指定比例、文字或风格时优先采用，不将当前模板设为所有封面的唯一外观。封面中的左右位置不代表胜负；不自动添加一图流的求饶表情、大于号或结果配文。

默认复用上述资产，不为每张封面重新生图。宿主没有生图能力也能使用现有模板，通过图片编辑工具或可用的Pillow等排版。需要新底图时，才调用宿主可用的生图工具制作不含角色的背景／图形素材；既有人物使用搜集素材拼贴。只有缺少明确形象时才按[文字角色设计](media-output.md#缺少明确人物图像先按文字设计角色素材)补角色图。人物生成规则不因海报模式而放宽。

透明模板固定同画布比例，默认16:9；背景和双方素材先铺满画幅，前景直接按原生alpha覆盖，不要求人物图沿分界或徽标挖空。默认无两侧红蓝光焰、能量带、长光线和散落碎片，避免遮挡人物。圆弧、刻度、墨迹或晶面之间的间隙按各款原生alpha透底，保留设计自身的实色与半透明细节；不能用半圆、椭圆或多边形包络简化轮廓，也不把棋盘格画成“透明背景”。新制透明素材优先让支持透明输出的生图工具直接生成，仅做必要的等比尺寸归一化，保留其alpha。布局示意图只作位置导航，不作裁切蒙版。

## 构图方法

默认款采用“双侧大幅人物近景＋窄幅机械分界与裁决环＋高对比VS”，双方底图在中线相接并延伸到前景下方；弧内空隙自然透出底图。其他专属款替换中央分界与VS造型；悬浮款不设中央分界，宇宙款使用中央星云沙漏和横标。两侧人物、中央标记是主要视觉信息；背景与边缘光负责衬托。可在底部加名字和必要的版本说明，并为角落水印留出空间，避免评级表、长结论与多个标题挤在封面上。

人物的脸、身体或动作线朝中间汇聚更容易产生对抗感，正面凝视、前伸手掌或标志性能力局部也可成立。不把参考缩成“两个正脸＋红蓝背景”，不要求所有角色愤怒咆哮；冷静、警惕、戏谑等神态由人物与本场气氛决定。

## 两侧角色图的选取

为每方比较多个对应版本的候选，先看单张，再放进同一版式里择优；可复用已有合适素材，不强制数量或另建审核表。

- **版本与配置**：确认时期、形态、服装和装备，避免用另一时期的战衣、宝石或武器替换本场配置。宣传图、电影画面、原条目配图及同人图须如实记录来源身份；媒体图不作为新能力证据。
- **辨识与气质**：保留脸、面罩、发型、衣领、标志装备或核心轮廓等能迅速认出的组合。姿态与表情符合本人，不只选“最凶”的一张。
- **裁切潜力**：优先头肩／胸像或脸部实际像素足够的图。大尺寸全身图的脸仍可能很小，不硬放大糊脸。非人角色可以核心或典型局部为主体。
- **朝向与分量**：优先相向或正面；比较同屏感受到的主体分量，不能只按原图大小等比摆放。眼部高度可大致呼应；为展示关键装备多留上半身时，仍保持脸清楚。需要镜像前，查看文字、徽记、独特伤疤和装备左右手是否会出错，优先换合适朝向的素材。
- **清晰与光照**：五官、面罩和轮廓清楚，可适度提亮与调色以协调同屏效果，不补造瞳色、发光眼、伤势或装备。原背景合适时可保留，不为透明底毁掉毛发与暗部。
- **版式适配**：实际放进模板查看，中央徽标不能挡住主要面部、眼睛或唯一身份特征。可以压住部分肩甲、胸口与装饰光效；遮挡不合适就移动、裁切、调整徽标或换素材。

SCP素材沿用[站内艺术优先规则](media-output.md#制作流程)，优先适配的黑白版画、剪影或线描，不限定画师。保留作者与来源，站内艺术不代表唯一官方定型；没有合适的版画时如实注明所用插画类型，不用其他项目的图替代。

## 背景的选取

背景先服务人物，再服务本场氛围，不为填满画幅堆特效。

- **联系角色与本场**：可从角色的环境、力量体系、气质及本次故事关系提取色彩和材质，使用合适的原场景、抽象纹理或新底图。不把海洋、科技、纸面或战场等示例固化成必用剧情或场景。
- **主体优先**：脸后少细节，强光与高对比纹理优先留在外沿或交界。暗色人物须有可辨轮廓，浅色人物不贴在同亮度背景上；需要时压暗或柔化背景。
- **两侧区分**：冷暖、明暗、饱和度、纹理和材质都能形成对照，红蓝只是可替换方案；同属暖色也可借轮廓和明暗区分。用分隔、排字与整体明暗维持系列感，不要求每场相同颜色。
- **表达准确**：背景可以是设计意象，不冒称原作实景或真实跨作品战场。星空、裂缝和光效不能暗示本场没有的量级、能力或装备，图像不反向参与评级。

## 轻量制作流程

1. 只取本场人物配置、显示名和必要版本短注；按上文选择素材与背景。不要把整份评级报告或视频属性表当作海报文案输入，也不因上游已有档位就自动排上去。无需为封面先选赢家。
2. 复用随包底图，或按用户风格另做底图。生图负责背景／图形素材，人物按现成图或文字角色设计规则取得；不将明确的既有人物交给模型重新定型。
3. 排版顺序：完整背景 → 铺满对应一侧并延伸至中央分隔下方的人物／原场景 → 少量氛围 → 一次同尺寸RGBA透明模板 → 必要的底部明暗与名字／版本。不要再给人物套中央徽标的半圆遮罩，也不要同时叠template与兼容副本。透明前景含模板原色，换风格可调色或重做。
4. 正常尺寸及缩略图下目视复核：双方是否好认、五官和标志装备是否可见、中文是否清楚、背景是否抢主体；尤其看VS周围能否自然透出人物/背景，是否还有硬弧、色底残块和白黑边。特效遮眼就调整素材位置或换图，不能靠粗剪特效解决。有问题直接改对应素材或位置；不调用评级验收、数学工具、回执、哈希或全项目测试。
5. 保存可交付成图；人物素材和底图按需保留，记录必要的出处与设计补完。未要求时不自动发布或附带其他媒体形式。

字体按宿主可用字体选择，不依赖某台电脑的绝对路径。模板随包提供，使用时不回到创作者工作区查找原图或示例。

## 专用排版入口

默认内容可直接使用随包`poster.py`，不用每次重写通用绘图脚本。它只接收两张图、显示名、版本短注、焦点和随包模板，没有评级/赢家/口号参数，也不读取评级JSON：

```sh
python scripts/poster.py --left left.png --right right.png --left-name "角色甲" --right-name "角色乙" --left-version "指定版本" --right-version "指定版本" --output poster.png
```

默认1920×1080、裁决环，仅叠一次原生透明前景。`--template`可指定另一随包前景，`--left-focus X Y`和`--right-focus X Y`用0—1焦点调整构图；人物窄图不适合再次cover裁切时，`--left-fit contain`或`--right-fit contain`保全原图并以同源柔化背景填满该侧。`--font`适配宿主字体。姓名和版本仍须由宿主准确传入，脚本不会识别混在名字中的多余文案，也不自动保证脸部可见。最终仍按真实大小和缩略图审看；用户明确另要扩展设计时用适合的编辑工具，不暗改默认模板文案。
