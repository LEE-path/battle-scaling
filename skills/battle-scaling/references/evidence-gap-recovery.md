# 缺口补链：查证、替代证据与可检验推断

用于独立定档、普通PK和故事版中出现的材料、属性、技能或交互缺项。增强主动查证和推理，不改变所选标准的证据门槛、[统一综合主档](modes-scaling.md)、状态继承及特能上限。故事版的媒介选择另见[文字取证边界](writing-rating-baseline.md#故事版取证边界)；普通评级／PK仍按原有媒体取证流程。

## 缺一条资料，先解决命题

不要把“暂未找到”“材料未命名”“没有同款交锋镜头”直接写成能力不存在、无法判断、只能读图或必须让作者补设定。先指出缺的究竟是哪条命题，它会改变哪个属性或胜路，然后主动选择其他可用的证据与方法补齐。

`待证命题 → 可支持／否定它的资料 → 替代参照或模型 → 条件匹配与反证 → 可采用的结论`

1. **复用并核缺项。** 先查配置匹配的已验收档案和相关来源，不因缺一个参数重做整个角色，也不把旧主判当作无需依据的答案。
2. **扩查相关对象。** 从角色扩到装备、攻击载体、受击对象、共同材料／目标、招式说明、正反战绩及作者／制作方的一手说明。改变别名、场景词和原语言检索；同一转述的转载不算独立旁证。
3. **换证明方式。** 找不到材质名可用实际破坏界限；没有直接交手可找属性相符的共同参照；缺单个精确值可用合理区间、上下界或结构关系。需要时调用既有物理、推导、叠链和资料检索工具，不局限于单站、单篇或单一模态。
4. **先比较条件，再传播结论。** 核机制、出力、作用部位、持续时间、状态和配置；只传播确实对应的属性。反例能否由状态差异解释应有依据，不能为保留胜者临时排除。
5. **给出足够明确的推断。** 前提充分时直接采用有依据的结论，说明推导与适用条件；尚有竞争解释时指出真正影响结果的变量。不是所有间接证据都只能得到“未定”，也不是合理推定都属于作者新增设定。

## 武器能否伤及目标：从实绩而非材质名出发

这是通用补链的一种应用，不要求所有战斗围绕兵器或环境取胜。按实际问题选择必要项目，不为每一刀强填全部参数。

| 证据环节 | 要查什么 | 能解决什么 |
|---|---|---|
| 武器／攻击载体 | 官方材质与结构、锋刃／尖端、质量和特殊性质；哪些已确认、哪些未命名 | 明确载体，避免擅称某种神金、无限硬度或无视防御 |
| 武器实绩 | 切穿／刺入／折断过什么，目标厚度、结构与终态；失败、磨损或被挡表现 | 给出实际破坏能力与限制，材质未知也可继续分析 |
| 目标防御与受伤 | 身体、甲、护盾分别挡住和被什么攻击突破；部位、深度、功能损伤及恢复 | 确认对应机制的耐受和破防锚，不把全身或所有攻击混同 |
| 致伤手段的参照 | 其他武器／材料／能量攻击有什么可比实绩，是否有共同靶、共同材料或明确关系 | 建立可追溯比较桥，而非因名字稀有就排高低 |
| 实际载荷与工况 | 谁提供力／功，速度、接触面积、刃形、角度、支点、持续；双方状态、留手与防御是否启动 | 区分材料属性、攻击出力与有效穿透，解释何种条件下能伤 |
| 命中后的结算 | 能否触及该部位，造成什么伤，目标还可做什么，有何恢复／脱离手段 | 防止“能伤”自动变成“必命中、秒杀、整体胜利” |

材料不存在可通吃一切工况的单一强弱榜。硬度、韧性、强度、耐热和特殊性质不同；同一种武器由不同使用者驱动，也不自动有同样破坏能力。需要量化时选与机制相符的受力、应力、做功、断裂或热模型，保留单位、接触和能量耦合；不能仅用一个焦耳值忽略几何与作用方式。

例如要判“某角色自己的武器能否伤到自己”，不必等待原作再演一遍自伤。可查该武器的破坏实绩、该角色已被何种同类攻击破防，以及两种攻击的可比载荷和作用条件；有相符的比较桥即可形成有据推断。武器切过甲、不等于它在任意持握／任何力道下都切开目标；目标曾被强力斧击伤、也不等于所有金属刀都能伤他。

只有间接关系确实成立才叠加：A在可比条件下达到或超过已能破开T对应防御的参照攻击，才支持A在该条件下能伤T。共同靶、材料对照或定量模型是桥，不得把“更硬”“击败过某人”直接写成跨机制的全属性传递。桥缺一环就定向补该环；无从证明材质身份时，保留身份未知而非停止全部推理。

## 其他常见缺项的替代路线

| 缺项 | 优先补法 |
|---|---|
| 没有精确尺寸／速度 | 官方尺寸、明确距离／计时、同场参照及合理区间；需要视觉测量时仅在允许该媒介的任务使用，不虚报像素端点 |
| 没有焦耳或吨数 | 同机制实绩、合法属性叠链、力／功／能量模型与敏感性分析；仍按具名规则落具体主估或有据下限 |
| 不清技能是否保留／可发动 | 查取得、升级、丧失、恢复与最近使用，核载体、资源、状态及配置继承 |
| 不清能否突破抗性 | 查该抗性的实际对象、机制、成功／失败和覆盖，找同层同类作用参照；不以AP或能力名代替 |
| 没有直接组合战绩 | 核组件实绩、时序、共存、命中、生效与阻断窗口；有条件可行的组合不要求原作曾完全照做 |
| 单站／单种材料读取受阻 | 查已有站点经验、其他原作入口、官方文字、可靠转录／资料与可访问版本；保留身份和阅读范围，不把摘要冒充全文 |

## 结论、停止与提问

内部区分**直接事实、有据推定、条件主估、创作选择与真实未决**。有据推定保留原作前提、比较桥和反证，不伪称直接画面；纯创作选择不能反填角色档案。有充分支持时作出判断，不用一串限定词逃避结论；缺充分支持时也不靠随意假设跨过关键限制。

当所选配置已完成[完整覆盖与综合选档审核](rating-completion.md)，九维与具体定档已成立、决定性交互有足够支撑且关键反证已处理，结束本轮扩搜，进入对应交付。只有新增矛盾或会改变结果的缺口才重开研究；完整不等于每个参数都必须官方精确标注。

尚无可靠具体定档仍按[独立定档](character-rating-workflow.md)继续补证，不能跳过准入。评级后确实残留不可消解且改变结局的关键冲突，才按任务给条件结论或询问作者一个最小问题。不得在尝试这些补全路线之前，把研究任务改成让用户判断材料、授予能力或批准一个方便的结局。
