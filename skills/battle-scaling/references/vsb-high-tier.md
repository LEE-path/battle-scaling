# VSB 高层结构与定性分级

适用标准：`vsb`；配置快照：`vsb-current-2026-10-21`。这是按需调用的中文执行摘要，不是汪吧高层名词的换算表，也不宣称角色得到 VS Battles Wiki 官方审核。有限能量档位另由 VSB 数值表处理。

`vsb_high` 的自动证据包审查覆盖 **3-A 至 0**；Tier 11 在本页给语义导航，由宿主查原作逐项评定，不能提交给自动高层审查或用零焦耳代替。有限数值工具只覆盖10-C至3-A。本包不把“列出档位”宣称为每档都有自动语义审核。

## 先做什么

每条高层判定必须分别给出：原作结构是什么、它怎样存在、角色实际影响了什么、作用是否覆盖完整结构、所用能力／状态、反例及来源位置。世界观拥有某结构，不等于角色能摧毁它；居住在高维不自动有对应 AP。程序只审查证据声明完整性，宿主负责阅读原文和检验声明真伪。

引用固定到来源页的 revision；本快照正文由 VSB 官方公开 MediaWiki API 读取，见末表。判定记录必须写明标准和快照。更新规则时重新核查变动条款；普通新角色不需要重复抓取同一快照。

## 3-A 至 Tier 2：先区分空间与完整时空

| 请求档位 | 必要结构与作用条件 | 不能替代它的材料 |
|---|---|---|
| 3-A | 对至少可观测宇宙大小的有限 3D 宇宙整体创毁／显著影响；标准也包括覆盖此空间的全向爆炸摧毁所有天体 | 仅一片星空、宇宙里若干天体、局部口袋空间；此档不要求创毁时间轴 |
| High 3-A | 3D 尺度实际无限能量、无限质量，或完整无限 3D 空间受到影响；仅算空间的无限个有限／无限宇宙也在这里 | 能源永不耗尽、无上限成长、夸张“无限强”；没有对应瞬时量级 |
| Low 2-C | 宇宙规模完整 4D 时空或同等显著高维结构被直接创毁／显著影响 | 时间旅行、改变历史、打碎过去后未来因悖论消失；只毁某时刻 3D 宇宙 |
| 2-C | 2～1000 个彼此分离的完整时空连续体受到上述作用，或等效结构 | 同一空间中被叫作多个“宇宙”的区域；多个 3D 世界却无分离时空证据 |
| 2-B | 1001 个至任意更大有限数量的上述分离时空 | 极大有限数被写成“无限”；仅能力比 2-C 强若干倍 |
| 2-A | 可数无穷个上述分离时空受到上述作用 | 一个无限大空间；容器理论上装得下无限宇宙但实际仅有限；仅无限倍强于 2-C |

FAQ 的完整时空包括相关宇宙全部空间和整个时间维，不只是一个时间切片。常规宇宙默认依 eternalism 处理；若原作明确采用不同时间本体，按原作重新判断，不能把默认覆盖明确反证。分支时间线默认向未来无尽延展；若全部分支仅有限时间分离、后来又合一，则按 FAQ 的完整时空要求重新计数。能以普通三维移动抵达的“两个宇宙”，默认不能仅凭叫法算两个独立时空。[Tiering System FAQ](https://vsbattles.fandom.com/wiki/Tiering_System_FAQ)

有限或可数无穷多个 2-A 集合的并集仍可数；“无限个无限多元宇宙”不自动升 Low 1-C。无界容器、宇宙间距、第五轴坐标只是索引用法时，不能擅自把第五轴放大成完整高维优势。Tier 2 子档间差距不能只用倍率跨越，甚至“无限倍”也不行；允许有依据地判同档更强。

## Tier 1 的数量、维度与定性条件

表中 R^n 只是通常对应，不是“写了 n 维就通过”。额外轴须有真实几何／结构意义与非忽略尺度；角色还须能影响合格结构。

| 请求档位／修饰 | 必要条件 |
|---|---|
| Low 1-C | 比 Low 2-C 高一个不可数无穷量级的完整结构，通常对应 R^5；或实际影响／创毁／体现实数基数个完整宇宙 |
| 1-C | 比 Low 2-C 高 2～5 个此类层级，通常 R^6～R^9 |
| High 1-C | 高 6～7 个此类层级，通常 R^10～R^11 |
| 1-B | 高 8 个至任意更大有限个此类层级，通常 R^12 及更高有限维 |
| High 1-B | 完整无限维空间的相应作用；覆盖所有有限维结构的合格统一结构可达此档 |
| High 1-B+ | 不可数无限或更高数量的维度／相应更高基数量性结构，按该 AP 修饰记录 |
| Low 1-A | 对应 Von Neumann 集合宇宙 V，囊括一切可能维空间或能够影响囊括它们的结构；已核实为对高维真正优越的泛指“超越维度”，无进一步上下文时也可按标准归此 |
| 1-A | 存在性质带来本体上的定性优越：下层的一切数量扩张、并集、排列／组合都不能达到；高层不可还原为下层构成 |
| 1-A+ | 有实际证据支撑的无限层上述定性优越，写 Outerverse level+；不能用无限个同层对象代替 |
| High 1-A | 超越生成整个 1-A 定性层级的框架／规则，构成元定性优越；比某个 1-A 再高一层并不足够 |
| High 1-A+ | 涵盖元定性、元元定性及一切可构想延伸，对应全部逻辑可能世界的逻辑空间；具任意大可能世界的实现能力，或体现全部可能世界框架，须分别证明 |
| 0 | 完全超出所有层级延伸，包含且彻底超出 High 1-A+ 的一切性质，并超越本体区分、对象分割和全部多重性；另须通过下节专门审查 |

这里的“不可数无穷层”是 VSB 结构标准的术语，不是把普通能量乘某个无穷数就自动升维。数量差和本体性质差分别论证，禁止把汪吧的“盒子／论外／天花板”字符串映射成 VSB 档位。[Tiering System](https://vsbattles.fandom.com/wiki/Tiering_System)

基数一定绑定其计数对象：可数无穷个行星、完整时空、维度会得到不同结论。序数的“更后”不等于集合基数变大；ω、ω+1 等仍可数。宇宙内数学课程提到大基数，不表示宇宙实际存在相应物理／本体结构。VSB 集合论说明采用连续统及广义连续统方向的公理约定；这是规则内约定，不能声称实数基数等于 ℵ1 已由通常数学无条件证明。[Set Theory Explanation Page](https://vsbattles.fandom.com/wiki/Set_Theory_Explanation_Page)

“无限更大”“高次元”“超越时空”“一切皆空”“更高存在”先核语境。“维度”可能只是异世界；没有时空可能是不同存在方式，而非优越。仅被称作高维、但没有合格出力／结构桥时，AP 可以是 Unknown。高维存在也不自动有 Immeasurable 速度；移动、额外时间轴与时间操纵分别核查。两个流速不同／逆行／平行的时间流不自动是垂直独立时间维；有限次改写时间线也不生成连续的不可数快照轴。[Higher-Dimensional Existence](https://vsbattles.fandom.com/wiki/Higher-Dimensional_Existence)、[Tiering System FAQ](https://vsbattles.fandom.com/wiki/Tiering_System_FAQ)

FAQ 对物理身体本身达到 High 1-B 或更高、且有跨无限维的非忽略移动者默认 Infinite Speed。仅 AP／远程能力达到高档不等于物理身体达到同档；此规则也不是 Immeasurable 的通行证。时间轴可像空间一样由自身运动自由前后穿行，与占满整个时间轴的全时存在分别判断。

## R>F 现实—虚构优越

真正 R>F 要有较高现实把较低完整现实当作无实在性的虚构的本体差；低层扩张不能达到高层，低层事态对高层的影响不应超过通常虚构对读者的影响。合格者按当前标准是 1-A 定性关系，而非固定“加一维”。作者／读者化身、梦、书、屏幕或游戏可作媒介，媒介本身不证明关系。

必须审反证：双方其实平行世界、性质相同或只有有限尺度差；作者也完整存在于自己写的同一媒介；下层靠原有下层力量即可反伤高层；作者化身仅搞笑出镜。具有较高现实根源的能力、提升后的跨越或特别机制，要独立证明，不能把每次下克上都当反证，也不能随意用“剧情杀”免检。

R>F 不合格不等于自动得到某个低一级档位。有证据的量性／维度结构可另评；仅有包含、投影、屏幕、纸片外观、较弱或“更真实”不能保底升维。角色操纵自己的下层小说，不自动可操纵另一部作品的同级作者。[Reality-Fiction Transcendence](https://vsbattles.fandom.com/wiki/Reality-Fiction_Transcendence)

## 定性以上的反例与 Tier 0

1-A 不能由低层数量逐渐累积而来，也不能只是某种低层能量分割后的极大一份。较高本体的赋能、源自高层的内在根源或非力量的信息联系可能成立，必须给具体机制；“受神力加强”一句不足以消除反证。只多一个同类定性层通常仍是 1-A 内分层；High 1-A 需框架级超越。

High 1-A+ 的逻辑可能世界不同于遵守固定物理定律的分支宇宙。原作使用更受限逻辑时，不能声称涵盖标准全部逻辑可能性；采用更宽逻辑时仍要证明至少包含默认经典逻辑允许的世界。体现全部逻辑空间的路径（FAQ 所称 Type 2）是最大构造；同一作品里多个独立此种“全部”、它们之间另有强弱差，应当触发反证审查。[Tiering System FAQ](https://vsbattles.fandom.com/wiki/Tiering_System_FAQ)

Tier 0 四项必要审查：

1. **首要性 Primacy**：没有更高、更根本、在先并约束它的东西。
2. **统一性 Unity**：超越所有性质多重性；不能有多个彼此排他的同级绝对者。多个称名可指同一绝对者，须有原文证明。
3. **不变性 Immutability**：不能在本体上从不存在变为存在、成长到该档、事后逆改为一直存在，或按外来事件改变内在状态。复归原本绝对本性和外部视角的顺序表现需结合原文区分。
4. **不可分性 Indivisibility**：不能是多个较低者融合所得、可拆的部件／份额；化身、恩赐与真体不得混成一个配置。

“全能”“不可言说”“超越一切概念”“万物归一”等单句不是充分证明；否定神学应指根本性质，而非低者暂时理解不了。不要为了四项勾选而忽略角色实际反应、被创造、受制、分裂或败北描写；普通措辞也要结合上下文，不能机械一词否定。

合格 Tier 0 真体不输出普通一拳力和逐步出招序列。其表格 Speed 默认 Omnipresent，Lifting Strength／Striking Strength／Stamina 为 Inapplicable，Range 为 Boundless；能力表按 Omnipotence／Omnipresence／可选 Omniscience 及已展示应用组织。标准明确认为两个 Tier 0 真体之间的普通战斗命题无意义，因此不能编造双方胜率、互相压制或具体胜局。可改评明确受限化身，但必须更换并声明配置。[Omnipotence](https://vsbattles.fandom.com/wiki/Omnipotence)

## BDE 与原 Transduality

Beyond-Dimensional Existence 当前区分：Type 1 无空间时间性质但未必优越；Type 2 以超出所有维空间的量性规模对应 Low 1-A；Type 3 因本体性质而定性优越，可仍有高层自身的空间概念。不能把 Type 1 自动视作 1-A。具空间坐标的高维形体，与无此坐标的抽象／BDE 真体分别标记；同角色的不同化身可不同。[Beyond-Dimensional Existence](https://vsbattles.fandom.com/wiki/Beyond-Dimensional_Existence)

`Transduality` 当前重定向到 **Paraconsistent Physiology**，新页分 Specific／General／Plurality，讨论性质如何不受经典真／假约束。不能沿用旧 Transduality 型号自动推出 1-A、High 1-A、抗一切能力或无条件不可杀；具体相互作用按原作逻辑及能力表现证明。[Paraconsistent Physiology](https://vsbattles.fandom.com/wiki/Paraconsistent_Physiology)
