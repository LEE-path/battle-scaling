# 独立角色量级研究任务

读取 input.json，只回答其中角色在指定作品、版本、时期、状态、装备和规则下的量级。任务等价于用户直接问“评定此角色量级”。没有新对手、预期胜者、情节和文风要求，不推测它们。research_plan 是可用的检索路线，尚未执行；按实际来源扩展和收束，不要求逐条机械搜索。先读任务所指共用流程，再按实际疑点读取绝对 Source 路径下的参考；任务不重复嵌入整份手册，列出路径不等于已经读过。

立即用当前宿主的真实搜索、网页阅读和文件工具开展研究。先查当前能力与表现及其来源，再沿对手、装备、同级／最强设定、世界观对象等关系核参照实绩；逐项思考较高主档是否更合理。查不到直接镜头时继续找可比交锋、官方设定、共同对象、参数或模型。定性关系正常有效，不要求原作提供焦耳；“很强”“神战”等概括也不能独自指定一个具体档。

将决定档位的论证先写成可复述的短链，实际依次做完：

1. **倒查起点。** 沿交手、最强/同级、装备或结构关系倒查参照者独立有效的实绩、可靠能力定义或本体依据。已有合格来源直接复用；循环交手没有绝对锚时先解决根部，不把所有中间角色无限拆成完整评级。已发现CASE可调用`research plan`附`case`生成目标的祖先缺口；没有CASE就用同样思路读原文，不为调用工具先造文件。
2. **解释两段关系。** 原文为何使参照对象具有该规模/层级；被评者又通过什么真实关系取得哪项对应能力。两段可由同一可靠句子确立，不强制两份独立材料。名称、身份称号、依存、共存、死亡伴随后果不能代替实力等价；也不因存在特殊机制就排除其确实支持的高位作用。
3. **正向归属。** 顺着已成立起点逐跳判断当次作用、状态、出力和结果，明确传的是身体、兵器、能量、硬防、抗性、修复还是其他实际能力。能交战、能伤、能杀、能恢复和胜负各有含义，不复制全属性；可靠综合战力比较仍可支持有理由的有效输出推定，无需逐项实演。重要缺环定向补查该环，已证反例限制对应路径，不删除独立成立的其他能力。
4. **一起选档。** 比较主要实绩、可靠设定、机制/本体和正反链后再选主档；说明为何落此细分、相邻或更高候选怎样处置。对所有参照、双方及高低候选采用同一证明尺度。允许有据语义主估，但须有实际尺度约束；不能对一方要求精确份额，对另一方凭“神级、劈山、很强”随手填惯用档。关键假设撤销后的影响写在原论证里，不另添审查表。

先交可读的 report.md 和真实来源记录 sources.json，不先编好评级 JSON 再把标签重复成所谓推导。报告首句给一个具体综合主档，随后是同配置九维与可核的来源、逐步叠法、重要候选的采纳／排除理由。对主档及重要属性说明：原文确立什么，对象有多大／多高，关系能传什么，如何对应规则，为什么取此档、为何不取更高候选。需要计算时只对有据模型计算，并列参数、单位和敏感因素；无法精确量化不妨碍合理语义选档。

原文、原作观察、引用转录、社区线索、推定和作者改编分别标明。provided_author_material 保留用户给出的性格、技能与显式改编，但其中未经核实的原作备注、旧档和预填数值不自动成为官方事实。scope_needs_host_isolation 非空时先请协调者提供被遮蔽的实际角色配置，不能用哈希作设定。

完成综合判断不要求每项都成为无条件实测定理。比较重要竞争解释后，明确选择上下文支持的合理主估，并说明撤销该解释会怎样改变结论；不要因为模型仍有明示参数、缺精确J或来源没有数学专名就一律退回最小物理地板。工具只能处理其给定模型；其不能自动定档，不等于原生结构与可靠比较不能支持定性主判。尚未查过或尚未实际处置的重要关系才继续研究，普通未知不无限扩充前置工作。

完成研究后把报告及最关键的原文位置交给协调者。协调者实际复核决定档位的来源与比较桥；遇到实质缺口，回到对应来源补研究。研究代理不代替协调者填写 accepted，也不把程序成功当作其已经理解原文。无代理时，宿主先完成同一单人研究，随后重新核对具体决定链；不能用文件制作代替任一阶段。

内容就绪后按[真实档案交接](rating-handoff.md)保存实际结论。纯定性研究可单份dossier，需计算时直接引用既有CASE及结果，不制造空算式或复制十条主张；旧八文件档案继续兼容。数值计算、表现／特能审查及推导工具按所需模型调用。此任务只研究角色，不写战果或故事，不加载写作范例。

任务生成、可读来源标签与程序传播都不认证上述语义。`derivation chain`返回的`research_tasks`可直接作为定向搜证待办；只处理会改变所求结论的缺口，更新原有来源/锚/边/报告。已处理的同一根锚、同源上下文与未变计算复用，不按每条下游路径重复查证。
