# 故事版的完整内部评级

故事版入口先实际执行[独立评级阶段](story-rating-first.md)：逐角色完成可单独交付的报告、来源及实际单人分析，主机实际读后验收，再由流水线导入。写作输入中的评级包只能承载这些产物，不能代替研究。

用户确认：故事版先在内部完成双方完整量级与九维评定，正文只写故事。**直接调用[独立角色量级评定流程](character-rating-workflow.md)，逐个取得具体主档和九维卡后才进入故事PK，不另用简化的能力核查代替定档。** 写作版改变呈现形式，不降低战力核查标准。人设、文风和精彩动作的定向取样不能替代这一前置工作。

独立报告须先通过[评级内容的优先级与语义验收](story-rating-first.md#评级内容的优先级与语义验收)：具体档位与重要比较链有来源、有效属性桥和选档理由，再交给写作；语义估档、低置信标签或程序通过均不代替该项。武器对抗、身体承伤、合击贡献与灾难终态按实际因果推导，不能靠未证的高／低子档安排胜负。

旧`normal/highest/lowball`独立包只作历史材料：先补核完整对象、重要外层关系、候选取舍和当前配置，再生成`mode:integrated`的新验收行；不能仅改标签或沿用旧通过结论。已核且未变化的原文、能力档案、计算及依赖校验可以复用，避免无差别重做。

## 故事版取证边界

仅`purpose:"writing"`采用本节。保留完整独立九维、具体主档与适用属性定档、宿主验收及关键能力／抗性交互，取消强制图像取证这一媒介步骤；独立评级、普通VS与`overview/process`维持原流程。

- **默认不新增读图任务。** 不为故事例行下载影视、抽帧、逐格／逐帧核验、OCR核图或像素测量；也不因原作是漫画就自动启动视觉流水线。用户明确要求依据新图片／视频分析时，按该素材任务要求处理，不默默把它扩成整场重新取帧。
- **优先复用与文本查证。** 配置匹配的合格评级档案可直接复用其中已验收的画面结论，无需重新看图。缺项查原作文字、官方剧本／说明、已核转录、作者或制作方一手材料及可核来源；可信二手资料用于交叉核对与导航，来源等级不自动抬高。不能把未读图片、未校勘OCR或搜索摘要写成自己已核原作画面。
- **缺直接镜头不等于缺证明方法。** 主动用[缺口补链](evidence-gap-recovery.md)检查武器／能力实绩、目标正反表现、相关材料与共同参照、实际出力及受击工况，形成可追溯推断。不从“不知道材质”直接跳到“只能问作者”，也不把有据推断全部当作自由创作设定。
- **达到准入后收束。** 按[完成性协议](rating-completion.md)审核近期实绩与重要候选，九维和具体主档已有充分依据、关键交互与反证已处理，且当前修订有效，才进入人物与战局创作；不是得到第一个低位数值便结束研究，不为非决定性的精确J、尺寸、图像复核继续扩搜。决定胜负的缺口仍须补齐；取消读图不等于任意补能力或略去定档。

普通评级／PK引用本页时，只复用写作衔接信息，不继承本节媒介例外；实际声称某一视觉观察时，仍须真实看过所引用图像。

## 先建立可复用的能力底稿

1. **固定配置。** 作品、连续性、时期、状态、装备、人数和可用支援分别固定。按[统一综合评级](modes-scaling.md)实际执行独立定档，使用 `mode:integrated`；作者指定的状态、改编配置或结局分别保留，不能由指定胜者倒推原作档位。VSB沿用其定义与证据门槛，不混用汪吧封顶。
2. **盘点档案。** 先打开最新状态与复核，只复用同版同状态、覆盖完整、选档审查完成且当前修订仍经宿主实际验收的评级。历史`accepted/ready`不能覆盖撤回，已知状态传入`rating_status`。补查新状态、资源变化和本篇关键交互；旧档仅列过技能、社区档名或几段摘录时，不算合格完整评级。
3. **缺档先独立定档。** 执行共用流程中的搜证、单次表现审查、实绩归属、物理推算与叠链，再按研究版量级卡验收；取证媒介按本页文字优先边界，不强制新读图。未有合格档案的小说角色优先论战拆书。完整对象、重要高位候选及外层关系比较完成后，选有据的具体综合主档并注明估计条件；尚未穷尽上限可记录缺口，不能用子结构保底代替综合主判。已知重要高位候选未处理则仍未完成。不能用“未定”“高等超人类”或一个方便量化的局部地板跳到故事编排；已验证参数与已校勘规则不重复回图。
4. **明确作者覆盖。** 原创和作者完整给定的改编设定，同样建立九维与能力底稿，以给定规则为依据，不寻找不存在的原作。部分覆盖只替换明确更改部分，其余仍核原作。指定胜者不能替代属性评定，更不自动授予新抗性或能力。
5. **交互先结算。** 查清实际可用的能力、成功与失败表现、发动、速度、对象、上限、代价、抗性和恢复，再规划组合。关键控制按[认知与抗性规则](writing-battle.md#先结算控制认知与抗性)结算，不从AP或“聪明”补出全部属性与清醒。

## 九维都要评，但不伪造精确值

每位角色逐项记录`具体主判档／适用能力等级 → 具体原作位置或作者设定 → 计算、叠法或定性推导 → 适用状态与限制 → 已证下限／合理估档／条件估档`。采用研究版的[属性卡定义](rating-card.md)，默认不向读者展示此表。未测精确参数与未穷尽上限另记缺口，不能作为适用主档或主要属性的最终评定。

| 维度 | 内部必须核实的内容 |
|---|---|
| 输出 | 拳脚、兵器、能量及特殊攻击分别定档；可计算时保留参数、公式、单位与合理区间。 |
| 体防 | 肉身、铠甲、护盾、局部弱点与抗性分开；承受一次冲击不等于免疫推进、持续压力或控制。 |
| 智力 | 观察、分析、学习、知识和信息来源依实际表现分级；不编造IQ或焦耳值。 |
| 战斗智商 | 试探、识别反馈、变招、资源分配与误判的原作实例；不能把设定标签变成预知。 |
| 经验 | 经历过的战斗、敌手类型及相关情境；年龄、身份不自动换成实战经验。 |
| 特殊技能 | 逐能力的实绩、对象、影响上限、前置、范围、消耗、失败及对应抗性；按所选标准判定。 |
| 破坏 | 实际毁伤范围、方式、结构和持续时间；与单点输出独立，不把总能量全算进每一击。 |
| 速度 | 移动、攻击、反应、发动和弹体速度分别评；核实际距离、时间与是否预判，防止全属性互抬。 |
| 体量 | 身高、质量、体积、结构、受击部位与失能方式；需要时补恢复、承伤总量和原作HP机制，不凭体型编造血条。 |

决定战果时另外补**举力／抓握与持续控制、续航、恢复、射程、感知**等必要属性。抓握强弱不能从一次打击的焦耳值直接推出，能量、力、功率与时间不得混算。高层结构与特能也不强行折成有限能量。

“完整”同时要求**完整对象覆盖与综合选档完成、当前修订有效、独立定档完成**和九维审查完成，结论可追溯，关键胜路及反制已核对。主档及适用输出／体防／破坏须有具体综合主判，并记录已证下限、估计和限制；精确数值未知、上限未穷尽仍可如实保留，但局部下限、主档模糊或未定不能放行。尚无可支持的下限就继续独立研究，受阻时保持评级未完成；不能先选停战或有限试探把缺口改称非决定性。已定档后仍有交互缺口，按[缺口补链](evidence-gap-recovery.md)主动查相关实绩、共同参照和工况，形成有据推断；不能把缺直接镜头自动归为作者创作关系。完成这些方法仍有决定性不可解冲突，才请作者固定最小条件，不得用该关系伪造原作档位。部分覆盖不能标为完整原作评级。

## 评级之后才编排与交付

特殊技能盘点也覆盖有依据的第四墙认知、媒介互动及卡通动作／恢复。按[角色基调、第四墙与喜剧因果](writing-tone-and-gags.md)分别核元认知、实际信息与操纵权限；不能把它们一概删成“只会吐槽”或普通人受力，也不能从喜剧身份推出无敌、全知或控稿。其实际作用进入本篇战术与后果，证据标准及能力上限不放宽。

在本场目录保存独立角色报告与九维卡，引用可复用档案及本次补证，和创作稿分开。按[共用交接](rating-handoff.md)导入真实产物，顶层`independent_ratings`是已审定权威；`fighters[].ratings`由它派生，旧摘要不能覆盖当前结论。作者局部改编用有实际设定来源的显式覆盖，仅改变该场对应属性，不篡改原作档案和接受记录。九个非空字符串、引用ID或`ready_for_host/structure_checked`均不证明原作已读、推算正确或评级完成；宿主须实际验收。缺独立定档时工具返回`needs_independent_rating`，不放行正文。

根据已定的输出、防御、速度、控制与抗性设计合理行动空间，再写人物、节拍和结局。完成后反查每个关键动作是否超出已定速度／出力／体防／力量／认知，反击是否真能发动，消耗和恢复是否连续。发现漏项先补评级并重审战局，不能只给正文加一句解释。

评级必须落实到[本场实际PK](writing-battle.md#实际pk与故事编排)：记录请求中各方的核心冲突、可行胜路与对应范围的战果，并让正文通过真实行动和能力交互兑现。情节形式按人物、设定与作者要求自由编排，不预设剧情类型；不能内部评完后绕开核心对抗，或以其他叙事成效替代既定胜利条件；单向控制与无效反抗也须按评级如实呈现，不强求互伤。

默认交付连贯故事，不附评级表、胜率、证据审计和逐字私有思维过程。用户另要依据时提供可核查的结论、计算与来源。实际完成的原作研究可按研究流程保存复用；故事里的新战果、创作兼容关系和作者覆盖不能反过来成为原作证据。
