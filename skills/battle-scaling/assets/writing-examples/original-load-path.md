# 最后一截栈桥

> 原创合成教学范例。人物、装备与城市均为本项目自设；用于示范物理交锋、吸能限制和非致命胜负，不构成任何既有作品的证据。

塔吊倒下的时候，连桁正站在桥面中央。

他把两只手掌按在路面上，护臂的十二格指示灯一齐亮起。冲击撞进蓄振层，桥面猛地一沉，随后停住了。桥下运盐的卡车刹得车轮冒烟，司机从窗口探出头，问是不是能开过去。

“倒车。”连桁咬着牙，“你这一车盐，够给我上半年坟了。”

另一端，岑迭已经解开牵引机的保险。她身上没有铠甲，四条拇指粗的牵引索从腰侧绕过大腿，接入地面的滑轮座。随着她后退，塔吊被一点点拖离桥面。最后一辆卡车倒出了危险区，她立刻踢开支架，任钢梁落进河里。

连桁收回手，十二格灯灭掉七格。

“够了吗？”岑迭问。

“够证明你的索具比我的手臂长。”

她指了指桥头的工会旗：“救援竞标还剩最后一项。你刚才说，一个人就能把我们全队挤下去。”

“我说的是总成本。”

“那就试试。先碰到对方背上的红扣，谁赢谁拿主承包。设备损坏各算各的。”

他看看那条清空的检修栈桥，点头。

岑迭先把索具卸成两条，以免有人掉下去时来不及松开。连桁也把护臂的泄压口朝上转了半圈。两人都看见了对方的动作，没有再多说。

连桁第一步就把栈桥踩得发响。

岑迭没有接他的拳。她侧过身，让右索从护栏底下绕回来，索环套向他的腰。他伸手抓住索环，向前猛拽。她脚下滑出半米，立刻松开卡榫，把这一段索送了出去。

他手里忽然一轻，肩膀已被她撞中。

三格灯亮了。

连桁笑了一下，反手拍在护臂上。蓄振层把刚才存下的冲击向外释放，近处的空气发出一声闷响。岑迭被推到护栏边，双脚还没站稳，第二拳已经到了。

她抓住护栏翻出去，挂在桥边。

“这个不算出界？”连桁走过来。

“合同没写。”她说。

索头从桥底升上来，扣住他的左脚。

连桁猛踩桥面，想靠反震挣开。灯又亮起两格，索却没有松。他低头才看清，那根索不是往后拉，而是穿过桥底两个滑轮，把他的脚向正下方压。

岑迭握住手轮，一圈一圈地收。

没有撞击，没有他熟悉的蓄能亮光。左膝只是越来越难弯。

他把右脚向前挪，想用腰力扯断索。旧桥的横梁先呻吟起来。

“桥比索弱。”她在桥外提醒。

他没有继续硬拽，改用剩余蓄能冲向桥边。岑迭已经把手轮卡死，顺着另一条索荡到他身后。连桁听到滑轮声，抬起右臂封住红扣；她的手却先碰在他肘内侧，向上一托。

这一下不重。他能顶住。

可他顶住的同时，左脚仍被固定，身体为了平衡，只能向右转。

岑迭等的就是这一转。她把自己的肩送进他右臂下面，用腰带上的短环扣住他护臂的连接杆。收索，转胯，再收半寸。他的右肘被缓缓提到肩上，红扣彻底露了出来。

“等等。”他说。

“认输？”

连桁试着把右肩压回去。短环绷紧，受力沿着护臂连接杆传到肩部。他的肌肉在用力，灯却一格也没亮。

她没有靠一记重击打穿铠甲，只是用桥做支点，用索固定他的脚，再把他自己的护臂变成了撬肩的长杆。他如果坚持，先脱臼的会是肩膀。

“认。”

岑迭碰了红扣，立即松开手轮。连桁把肩膀活动了两次，确认关节没伤，才去解脚上的索。

“你那四条索全带上，我是不是连第一拳都不用出？”

“不好说。你也没把泄压口对着我。”

他看了她一眼。

“主承包给你。总成本那一栏，我重新算。”

岑迭把手递过去，拉他跨过断掉的一块桥板。

“先算桥。”她说，“刚才踩坏的两根，设备损坏各算各的。”

连桁看着桥头的工会旗，终于明白自己在什么时候输掉了第二笔钱。
